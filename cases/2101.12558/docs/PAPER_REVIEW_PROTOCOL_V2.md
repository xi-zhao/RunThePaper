# Paper Review Protocol V2

A fresh reviewer must first inventory every numeric axis and quantitative claim
from the frozen paper-only bundle. Only after freezing that inventory may the
reviewer inspect equation cards, independent code, generated data, and run
attestations.

For any proposed paper error, the reviewer must provide two scientifically
independent strong checks, an explicit falsification attempt, source pinpoints,
parameter sensitivity, and evidence that reproduction defects, compute limits,
and alternative interpretations were excluded. No candidate exists in the
current code-ready-only state.

The included review bundles are requests, not review results. Lifecycle
promotion remains blocked until a fresh-context reviewer submission validates.
