# Formula Verification

All formula cards require source tracing and an independent commutator, direct-minimization, positivity, limiting-case, or trace identity. The separable-extremum sentence is recorded as a source discrepancy rather than silently forcing the implementation to reproduce the printed number.

This document explains which formulas are allowed to feed numerical reproduction.

