# Numerical methods

- 100,001-point global angular bracket plus bounded scalar refinement.
- Exact analytic derivatives for the magic-angle asymptote.
- Dense Hermitian spectral norms for even rings `N=4,6,8,10`.
- SciPy matrix exponentials for the time-ordered Floquet word and homogenized comparator.
- Double precision is sufficient; residual comparisons are at `1e-12` except the controlled `1e-5` asymptotic sequence.
