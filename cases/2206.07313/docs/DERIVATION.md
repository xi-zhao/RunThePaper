# QC19 资源与线路复核

每个访问位置用 $n$ 位独热标签或 $\lceil\log_2 n\rceil$ 位二进制标签，固定 140 个位置乘上每标签位数。其一般比值为 $n/\lceil\log_2 n\rceil$，固定车队容量只容许 $n\le 140$。如果车位随乘客扩张，至少要线性增长。用 4 客户和 2 辆车的有向代价矩阵，穷举二进制寄存器和经典排列并逐一核对可行成本。交换两个标签保持排列集合，任意加权需求约束需另外处理。

按 Qiskit 的 $U(\theta,\phi,\lambda)$ 和图示控制方向传播图 3 的四个 CNOT 线路。初态取 $|00\rangle$。初始上位门只作用于 $|0\rangle$，$c_1$ 不影响此初态。矩阵乘积可化为 $p_{00}=p_{10}=(1+w)/4$、$p_{01}=p_{11}=(1-w)/4$，其中 $w=\sin(2t)\cos[\theta(c_2+c_3)]$。256 组参数检验该化简。逐寄存器读出时，两个不同标签总概率为一半。若下位是路线位而上位不作条件，其可确定选择路线。原实验的解码映射决定哪种口径适用。

误差减少为 $(1-p_{\rm base})/(1-p_{\rm improved})$。图 4a 栅格读图以轴零和一及误差像素区间核对。成功概率比另计。
