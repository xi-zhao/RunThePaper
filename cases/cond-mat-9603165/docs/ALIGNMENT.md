# Hatano剩余残差：在原尺度集合波动内统计相容

按原L=500、均匀势[-1,1]、能窗.04、每集合100条链，计算100个无序集合，共10000条独立随机链；不按原图选择种子。固定采用原坐标区间的连续指数标定宽度倒数，与峰值展开宽度作成对控制。

原图相对100集合均值的整曲线RMSE为.010193；模拟中单个100样本集合相对其余集合均值的RMSE中位数.013125，2.5%—97.5%分位为[.008238,.021209]。最坏标准化残差为2.997，位于模拟曲线分布约79百分位；内部区间与此前可疑肩部残差也在同尺度波动范围内。峰值展开坐标则仍有明显偏差，显示坐标定义确实重要。结果支持现有余差可由原尺度有限无序集合解释，未看到需要额外系统误差的证据。

后续长文Fig14的91个宽度曲线标记也已独立从EPS读取，与1996插图逐点纵坐标RMSE约.001999、最大差.003248，共享细节结构；这支持把长文宽度方法用于原插图溯源，不是证明作者数组逐字相同。离散指数包络的asinh标定以及不同平均顺序另作配对检查：没有一个简单修正能统一改善全曲线，不选择事后最贴图的函数当作作者定义。

这是在明确宽度定义下的条件性统计支持。集合分布与比较统计是在看到前轮差异后选择的诊断，所给百分位不是预注册p值、整体正确概率或复现分数。作者精确种子/代码身份不作为额外完成要求。原谱、电流及去局域化主要结果继续得到支持。
