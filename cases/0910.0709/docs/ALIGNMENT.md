# STA绿色平台：直接Schrödinger传播确认条件性不相容

由给定频率和端点匹配得到总时长2.092094764 ms；原图注写2 ms。这一时长差不改变由末态固定的能量平台判据。

本轮增加实空间波函数的分裂算符FFT传播，不在演化中使用Ermakov宽度解。两组网格2048/4096、三组最大步长.004/.002/.001交叉核验。最细结果：换频后的能量50.00499121，末态能量.01000000000034，目标基态保真度.9999999999927；随时间步加密趋向代数结果50.005。归一化误差约1e−12，边界概率小于1e−22。

为检验平台1的状态解释，另做明确的非原文控制：在换频时重置为初始基态。第二平台确实变成1，但最后能量是.50004994，目标保真度.19801981；解析值分别.50005和20/101。这证明不能靠这个状态替换同时恢复绿色平台1与原文末态冷却目标。并非积分容差或小数精度问题。

当前可明确的结论是：若绿色线表示文中已指定Hamiltonian、同一连续演化状态的物理能量，平台1与这些条件不能同时成立。差异已定位到第二段所配的状态/能量量，而不是我们的Ermakov实现。具体绘图中间量或代码操作尚未识别；没有证据说作者确实做了重置或复制。最终冷却、平滑协议和加速主要结论继续得到支持；受影响的是这条瞬态能量成本曲线。
