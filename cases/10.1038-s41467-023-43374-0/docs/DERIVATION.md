# Calculation / 计算方法

Propagate the finite momentum ladder by both diagonalization and matrix exponentiation. Compare the literal and resonance-consistent Hamiltonians at fixed pulse width and check convergence under time-step and cutoff refinement. The separate XLSX reanalysis accepts the publisher's source-data file as an argument.

[Paper](https://doi.org/10.1038/s41467-023-43374-0)
