# QC24 模型与复核

CPMG 以论文的瞬时 π 脉冲极限建模。翻转时刻为 $t_j=(j-1/2)T/N$。符号函数分段取 $(-1)^j$，直接积分各常值段得到频域幅度。另一算法逐段对实部与虚部积分。固定 $N$ 时频率峰位按 $1/T$ 缩放。非负反演另以固定输入谱、同一噪声和同一二阶差分罚项比较无约束与有约束解。

复合脉冲逐段计算 $U=\exp[-it(\cos\phi X+\sin\phi Y)/2]$。噪声算符在理想控制的相互作用绘景中积分，弱正弦驱动用含时传播交叉检查。原论文未随图提供当时各组波形与逐次读出。

原始 iSWAP 在单激发子空间的哈密顿量为 $X/2$。取 $\Lambda_{\max}=1$ 时历时 $\pi$。静态差分噪声在外层给 $\pm \pi/2$，单激发子空间中积分后的算符为单位模 Pauli。归一化二阶代价为 $\pi^2/8+1/2$。用积分和直接有限失谐传播分别复核。IBM 回波的 SWAP 反转差分 $Z$ 算符。对 50 个空闲门，中间 $j$ 段的相位与外部反号，概率为 $\sin^2[(50-2j)\phi]$。

五 qutrit 算例使用表 III 的 $2\pi$ MHz 系数，等待用微秒。按式 (105) 指数化五个局域三阶哈密顿量并作张量积，式 (109) 的等待演化为对角阵。式 (101) 给两对相位门，余下一个 qutrit 恒等。乘积的稠密传播、随机向量上的逐轴张量收缩、等待导数中心差分分别核对。对取整误差采用矢量化酉算符的射影角 $\arccos(|\operatorname{tr}(U^\dagger V)|/D)$。单位酉作用保持距离，用三角不等式相加各段上界。局域项迹为零，归一化 Frobenius 方差可相加。对表 III 的 16 维区间，凸二次型上界取所有顶点。分别计算固定两位与各字段显示精度两种区间。
