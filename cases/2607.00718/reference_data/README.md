# Author comparison data

The MATLAB arrays in this directory are the open author dataset deposited as
Zenodo record `10.5281/zenodo.17231964`, licensed CC BY 4.0 and attributed to
Liu, Wang, Tang, Chen, Jing, Su, and Nori.

They are comparator inputs only. The reproduction code first generates every
curve from independently transcribed equations or Gaussian dynamics and loads
these arrays afterward to measure agreement. The arrays are never used to fit,
digitize, interpolate, or construct generated curves.

The deposited transmission arrays correspond to an earlier manuscript version.
They are retained for provenance but are not accepted as final-paper ground
truth.
