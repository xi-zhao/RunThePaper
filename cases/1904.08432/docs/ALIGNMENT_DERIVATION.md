## 为什么稳态求解会改变基线

记 s=γg/(γₗ+γg)。式(5)为

    dC/dt = XC + CX† + 2Mg.

在 t₁=t₂、偶数胞元的周期链中，k=π 的暗模投影 P 满足
XP=PX†=MgP=0，tr P=1，每胞元的 tr(P_x)=1/L。
所有下列矩阵都是物理的稳态相关矩阵：

    Cη = s(I−P)+ηP,  0≤η≤1.

因此至少存在这一族稳态；本文不将这一事实解释成主要物理结论失效。
源文给出的 sI 对应 η=s。对于满填充初态，真实演化为

    C(t)=sI+(1−s)e^(Xt)e^(X†t),

有限偶数链的长时极限对应 η=1。无约束的最小 Frobenius 范数解对应 η=0，
因为 ||Cη||²_F=(2L−1)s²+η²。对同一条演化曲线减去不同参考：

    nη(t)−ns(t)=(s−η)/L.

等增益、损耗时，η=0 比 sI 的曲线高 1/(2L)，而减去真实的满填充长时极限
则低 1/(2L)。前者与原图周期曲线相容；后者不会改善这处偏移。

本轮不是在图上自由拟合这个常数：直接使用 SciPy 的 Lyapunov 求解器，
在 L=30/60/150 和四组增益、损耗率下均数值选到 C₀。小系统的独立 SVD
最小二乘也得到 C₀，截断阈值从 1e−8 到 1e−14 不变。
奇数链、开链和偏离 t₁=t₂ 的满秩控制恢复 sI。
这是可重现的算法机制；不证明作者实际采用了此算法，更不是所有求解器
或任意舍入扰动都必须选 C₀ 的定理。使用退化稳态方程时仍需指定暗模占据。

## 初态能否解释正偏移

任意物理费米相关矩阵满足 0≤C_initial≤I。同一 X 下两初态之差满足

    C_filled(t)−C_initial(t)
      = e^(Xt)(I−C_initial)e^(X†t) ≥ 0.

所以在固定参考下，换成其他物理初态不能使每胞元密度高于满填充轨迹。
原图相对于 sI 参考的正偏移，不能靠简单更换物理初态解释。
这是模型内的矩阵序结论，不是有限组初态测试的外推。
另以空、半填充、满填充的直接仿射 ODE 核对矩阵指数演化。

## 原图精度与数值误差分开检查

从作者 EPS 读取折线端点，不使用旧 PDF 标定或生成网格插值。
全部可辨识刻度决定轴的仿射标定；原曲线的纵坐标不参与拟合轴或模型。
直接在读取的时间点计算。长度和参考态只在明示的离散候选中比较，
另分 t≤20 和 t>20 检查最佳候选是否改变。

EPS 坐标呈 1/256 绘图点网格，十进制保留三位。使用 ±0.003 EPS 绘图点
作为坐标不确定度，并检查 ±0.0025、±0.004 的敏感性。刻度和曲线端点的
坐标误差均传播到比较区间；满足所有刻度约束的轴参数多边形由线性不等式
求得。周期曲线单调下降，因为 X+X†≤0，因此用时间区间端点界定预测值。

“全部点在误差带内”指每个端点的预测区间与图形读取区间相交；它不是
作者原始数组相等的证明，也不保证每个点独立取到的区间端点能由同一个
轴扰动同时实现。中心标定固定为仅由刻度得到的最小二乘标定，另列实际
中心残差及相对 RMSE。该分析不是像素误差评分。
