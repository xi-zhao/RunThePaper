# Haldane 原始模型：零外磁场的量子Hall响应

原文为1988年PRL61,2015–2018，出版社PDF可由网页读取工具完整读取；本地PDF下载数次被403/传输失败，已保存带页码的原文提取文本及各次失败记录。该访问差异不是作者信息缺失，也不阻止方程计算。原图像素仍需获取可保存的原图，不能把重画当成原像素。

固定几何a1=(1,0)、a2=(−1/2,sqrt3/2)、a3=(−1/2,−sqrt3/2)，a1×a2>0。b1=a2−a3、b2=a3−a1、b3=a1−a2，令u=k·(a1−a3)、v=k·(a2−a3)。选周期晶胞规范后g=t1(1+e^iu+e^iv)，H_AB=g*、H_BA=g；dz=M−2t2sinφ[sinv−sinu+sin(u−v)]，d0=2t2cosφ[cosu+cosv+cos(u−v)]。不把可省略的单位矩阵项误当成不存在的粒子空穴对称。

两个Dirac质量m±c²=M∓3sqrt3 t2sinφ，原文Hall整数ν=[sgn(m−)−sgn(m+)]/2。采用t1=1,t2=.1，满足原文|t2/t1|<1/3。图2是整个M/t2、φ平面的解析相图；另用下能带本征矢的离散环路相位在121×141参数点独立计算拓扑整数，临界闭隙点不强行赋整数。近边界加密动量网格，未解析点保留标志。

环路乘积的符号与Berry联络/电子Hall电导约定一起固定，另以速度矩阵元的Kubo积分检验同一Hall响应，不能为贴合颜色随意翻号。临界线选一个一般φ点检查仅一个谷闭隙，原文高能伙伴恢复整数Hall而非半整数，是晶格正则化的物理含义。

弱外场只是原文推导响应的方法，不是零场模型的必需外磁场。对Dirac Hamiltonian计算Landau谱，核验n≥1的成对能级及n=0的谷/场符号依赖；有限振子截断上端会造一个假零模，按高截断态支撑排除并明确说明。

原图1是蜂窝跃迁/相位示意，核对正相位方向、A/B及零晶胞总磁通即可，不新增逐像素重画要求。加自旋后响应加倍的叙述以共同Fermi隙存在为条件，Zeeman移位可令其金属化；本任务不制造实验实现的证明。

符号复核修正：在上述定向与 A=i〈u|du〉 下，正向重叠链接计算 −C_A，质量公式给 C_A。最初实现将两者直接比较，错误标记了全部7930个非平凡有隙点；前次实验与审计报告保留。新版显式输出 C_A 以及常用 j_x=σ_xy E_y 定义下的 −C_A e²/h。独立曲率积分和球面三角形拓扑度支持该字典。原出版图中方向、张量字形尚未取得可保存的原图像核验，因此不把内部修正冒充已确认原文所有 Hall 符号一致。
