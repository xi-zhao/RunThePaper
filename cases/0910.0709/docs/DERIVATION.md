# 固定原文与独立计算

当前计算锚定 arXiv:0910.0709v1，PDF 与完整 TeX/EPS 已保留 SHA256。期刊题名含副标题；未逐式取得期刊版之前不把预印本与出版版自动等同。

以论文的 ω₀=2π·250/s、ωf=2π·2.5/s、γ=10，求六个端点约束。多项式解 b=1+(γ−1)(10s³−15s⁴+6s⁵)；指数形式对 log(b)施加相同端点约束。Ermakov 方程给出 ω²=ω₀²/b⁴−b̈/b。能量除以初始基态能量为 [ḃ²+ω²b²+ω₀²/b²]/(2ω₀²)。允许 ω²<0，不能以正频率开方代替带符号曲率。

独立核验直接积分 Hamilton 方程的 2×2 基本解，在(q,p/ω₀)坐标传播初始单位协方差，能量由协方差算出；并比较两个积分容差。该方法不积分 Ermakov 方程，也不读取原图路径。二次 Hamiltonian 的这一传播同时确定各 Fock 态的能量，乘(2n+1)。末态为对应能级并保持布居；不同能级可获得不同相位，不声称任意叠加只差一个共同相位。

图3的 bang-bang 曲线从文中 ω₁=i0.9ω₀、ω₂=ω₀ 和 b、ḃ连续条件求解切换与总时长。将实际算出的时长与标题的2 ms分别报告，不靠图像回归切换点。

原 EPS 图4的三条起始能量为1、3、5（以初始基态能量为单位），图注却写n=1,2,3。计算保留零起点能级 n=0,1,2 和图注字面 n=1,2,3 两种标记；先核对出版版，不能先归责作者。图中数值是否一致应与能级标签问题分开。

后续已取得作者研究组保存的正式出版PDF，并核对Eq1/3/4及图3/4，两个显示/标签差异在出版版仍存在。以各段恒定Hamiltonian的精确2×2辛矩阵指数独立传播初始协方差，完全不使用b(t)能量公式，得到第一段能量0.095、第二段50.005、最终0.01；末态协方差diag(100,0.01)。所有突跳做功相加为−0.99，与最终冷却一致。原图第二段绿色平台仍为1，未解释其计算/显示约定；不能把这个差距说成浮点误差，但也不据此否定平滑协议或主要冷却结论。实际数值保存在results/bang-jump-audit.json。
