# Source comparison policy

These boards use limited excerpts from [Casimir effect for a massive scalar field confined between parallel plates with a spatially varying effective mass](https://arxiv.org/abs/2607.15070v1) only to validate scientific structure and declared numerical regions. The independent result is generated from the published equations or method. The case does not redistribute standalone source panels, the paper PDF, author arrays, or digitized point sets. Pixel similarity is not treated as author-data-level equivalence.
