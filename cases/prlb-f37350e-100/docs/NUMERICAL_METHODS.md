# Numerical methods

The only search is over integer shells in (d=2). With (q=e^{-cm}), (D(q)) is a concave quadratic and (q) decreases monotonically with (m=n_x^2+n_y^2). The continuous vertex lies at (m=32.99995598798843). The axis shell 36 is guaranteed representable, so enumerating every lattice mode with (m≤36) includes the closest representable shell on both sides and is sufficient.

No arbitrary momentum cutoff, continuum replacement, quadrature, optimizer, stochastic seed, or GPU is used for the benchmark result. Figure curves use deterministic dense sampling only for rendering; the tested values come from closed-form functions and exact finite enumeration.
