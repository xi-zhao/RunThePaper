# Figure classification

本论文的全部图资产都经过全文与补充材料联合枚举。图像范围包含 Main Fig. 1 的三个子图以及 Main Fig. 2、Supplement Figs. S1–S5，共九个数值图项；它们均由方程或明确方法定义，因此全部进入 numeric_reproduction。

fresh-context Phase 1 还在正文和补充材料中独立枚举出十九个可由理论、方法或代码核验的定量声明。它们不是额外图片，但属于论文审查的数字化范围；`figure_coverage.json` 将这些声明显式映射到已有 T001–T009 科学目标，避免“图都复现了、正文数字却没人检查”的范围漏洞。当前机器清单因此共有二十八个 numeric items，而生命周期目标仍是九个共享数值实现。

没有把文字、示意结构或原图装饰当成科学数值目标。对每个数值图，所有可辨识子图、态族、曲线和标注值都纳入目标合同；不存在仅复现一条代表曲线的降级做法。

分类权威数据见 figure_coverage.json。
