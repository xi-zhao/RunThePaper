# Rerun / 复算

Compute both control-quadrature filter responses from the toggling-frame path and compare single-tone reconstruction with pulsed DPSS transfer. Keep model kernels separate from the source spectral traces.

Use Python 3.13 and the [code instructions](../code/README.md). The entry point runs the following stages into a fresh directory.

- `public_model.py`
