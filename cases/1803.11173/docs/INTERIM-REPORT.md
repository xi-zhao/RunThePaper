## 本轮实际完成

- 对全部偶数 n=2…26，各重新计算 1,000,000 条无偏 Pauli 路径，深度至 512。它计算连续随机 Pauli 旋转线路的同一二阶矩，不是把量子线路换成不同的 Clifford 集合。
- 重新运行 beta=0.25 粒子估计：每尺寸 32 组、每组 20,000 粒子；n=6、20、22、24、26 再用 64 组、每组 100,000 粒子细化。标准误由独立整组重复计算，不把相关粒子当独立样本。
- 用小系统的确定性转移、连续角度复数态矢、切向量/参数移位/有限差分交叉检查。参数移位最大误差 3.61e-16，有限差分 4.95e-11，确定性概率守恒误差 8.88e-16。
- 原有 5 标准误诊断全部满足：态矢与路径最大差异 3.38 SE，路径与粒子 4.77 SE，粗细粒子 3.89 SE，深平台与解析极限 1.90 SE。不过 n=26 过渡区粒子相对 SE 仍最高约 7.25%，不是高精度曲线。
- 完整重算耗时 195.68 秒、峰值约 123 MB；绑定原图的检查耗时 1.13 秒。只有本对话中的同一研究 Agent，无子 Agent 或外部模型。

## 为什么不能宣布原图通过

对明确的 RY(pi/4) 初态、第一参数轴也独立均匀抽样 X/Y/Z 的模型，独立组合计数与 Haar 推导均给出深平台 `D/[3(D^2-1)]`。图 3 的原始点约为此极限的 1.55–2.46 倍；但作者没有提供线性深度倍数和样本数，不能把有限深度差异直接归为论文错误。图 4 深层原图/计算的中位比例约 1.42。

固定第一生成元为 Y 会把深平台乘 3/2，但这是**诊断变体**，不能因它更接近原图就认定作者这样做过。作者样本数未知，也没有给原图虚构统计误差。矢量读取相对误差界约 0.083%，与未知采样误差分开记录。

## 解析结果及其边界

既有同一研究上下文的解析记录仍保留，本轮数值控制也重新验证了相关特例：

- 独立一侧为 1-design 时梯度均值为零；2-design 与有界算符条件给出指数压低的方差和固定阈值尾概率。这不意味着梯度严格等于零。
- v1 的有限维方差等式存在遗漏：单比特三种 Haar 情形的精确方差为 1/3、1/3、2/9，而印刷公式为 1/2、1/4、1/4；中心化迹和 D²-1 因子不能省略后仍称有限维精确等式。其大尺寸指数规律不因此失效。
- 一般非对易 W 的梯度分割需要共轭生成元或移动切分点；RY(pi/4) 也不是 Hadamard 的平方根。修正解释与字面命题分别记录。
- 单个可观测量达到平台不证明整个线路集合是 2-design；测量成本结论限于相应访问模型，不扩展为所有优化算法的普遍不可能定理。
