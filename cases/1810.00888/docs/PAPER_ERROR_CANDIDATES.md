# Paper error candidates

本文件保留旧 protocol-v2 评审提出的候选证据，不把复现缺陷、参数舍入或
算力不足混入论文错误。旧评审没有看到后来新增的参数来源合同，因此当前
权威分类已回退为 `inconclusive`；以下两项只有通过新 bundle 的 fresh-context
复审后，才能重新升级为 paper_error_candidate。

## PEC-DECAY（T001、T002）

论文正文在 Main Fig. 1 后写边缘能量的衰减长度为 2 ln(3)。补充材料的精确有限长度公式每跨一个二格点 block 乘以 1/3，因此物理格点距离的衰减长度是 2/ln(3)。

- 论文值：2 ln(3) = 2.1972245773
- 独立结果：2/ln(3) = 1.8204784533
- 不变量：相邻 block 比值精确为 1/3；论文值会给出 0.4024279410
- 交叉检查：解析重推；直接 MPS 与闭式分布最大差 1.84e-15
- 影响：正文长度陈述错误，Fig. 1 数值曲线本身仍可正确复现

## PEC-INVERSION（T006、T007）

补充材料称 bond-dimension-3 的 N 矩阵满足 Y_I N_I^s Y_I^{-1}=N^s，从而 Upsilon 态具有精确反演量子数。对打印的 N00 矩阵，该等式要求 nu5=0；论文却给出 nu5=-0.00128607。

- 局域规范矩阵残差：0.0072751105
- L=26 直接态反演残差：约 0.00215255 与 0.02702121
- T006 目标扇区权重：0.9999988416 与 0.9998174635
- T007 十三个态的扇区权重缺口：4.85e-8 至 1.40e-6
- 交叉检查：解析规范关系；完整谱权重归一与直接反演作用
- 影响：主要 overlap 峰和图形结论仍近似成立，但“精确反演量子数”不严格成立

旧结构化裁决保存在 `outputs/review/reviewer_submission.json`；当前
`outputs/checks/independent_review.json` 明确记录其为 `stale`。即使未来重新
