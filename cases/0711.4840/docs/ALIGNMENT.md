# 贝叶斯最优次数：已找到能恢复p=20的统计汇总，整条曲线未完全恢复

源模型、τ=1/√N、θ=π/2、平先验[0,π]及每条记录的68%区间保持不变。按原插图17组(Nₜ,p)各生成16000条记录，共272000条。将同一批区间半宽r作算术平均，Nₜ=200/400/800的最优p分别为10/16/16；作均方根sqrt(mean(r²))，三组均为20。均方根给少量宽后验更大权重，这提供了先前最优次数差异的具体机制。它不是参数拟合，也不表示已确认作者使用均方根，更不表示RMS区间自动等于估计量RMSE。

本批RMS最低系数依次9.321、9.389、10.191；三条原插图p20的系数约9.768、9.654、9.564。有限尾样本使RMS不稳定；500次经验重采样中，最优p20出现比例为100%、72.6%、74.2%，其余主要落在p16或25。这是有限数据的敏感性诊断，不是论文正确概率或普适p20定理。完整17点曲线仍有数值差异。

已做独立高阶积分：对真实生成记录的中位/最宽6条，用512分段、16/32点Gauss-Legendre积分及根求解检查。固定同一MAP时，Gauss阶数变化<1e−9；网格由16385加密到65537后，6项与Gauss差均≤5.34e−8 rad，满足事先5e−7阈值。旧网格有2项超出该严格阈值，实际积分差最大1.34e−6 rad；另有离网格MAP细化造成的约2.49e−5 rad定义变化，两者已拆开。没有把宽尾全部称作网格误差，也没有放宽阈值。

另检验固定制备时间τ=sqrt(20/Nₜ)而不随p调节（408000条额外变体记录），以及先平均似然/单次后验乘积再归一化等不同顺序，均未同时恢复原插图。保留原条件与变体，未取代原参数。还需核对的是作者实际如何汇总多条记录，而非缺少算力或已证明论文错误。
