# Source comparison policy

These boards use limited excerpts from [Deterministic atom-shuttle interconnects via ultrafast atom-ion entangling gate](https://arxiv.org/abs/2607.15597) only to validate scientific structure and declared numerical regions. The independent result is generated from the published equations or method. The case does not redistribute standalone source panels, the paper PDF, author arrays, or digitized point sets. Pixel similarity is not treated as author-data-level equivalence.
