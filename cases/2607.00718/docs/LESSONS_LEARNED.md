# Lessons Learned

1. A genuine author dataset can still describe the wrong manuscript version;
   compare formula landmarks and figure numbering before granting exact credit.
2. For quadratic Lindblad systems, derive the exact Gaussian reference before
   trusting a finite-Fock plot.
3. A source-looking low cutoff is not convergence evidence.
4. Scientific reproduction can verify or reject a paper claim; a justified
   rejection is not an execution failure and should not cause infinite retries.
5. Source arrays and pixels belong to the comparison layer, never the numerical
   generation layer.
6. Axis labels are scientific claims. Check units, limits, intercepts, and
   endpoints from formulas before assigning visual credit; Figure S3's printed
   absolute-energy label fails this audit while its normalized curves pass.
