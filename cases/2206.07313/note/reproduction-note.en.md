# Transport-route encoding

The fixed-capacity 100-passenger example requires 14,000 one-hot bits or 980 binary bits. All 24 feasible four-customer permutations agree with classical enumeration. [Paper / 原文](https://arxiv.org/abs/2206.07313v1)
