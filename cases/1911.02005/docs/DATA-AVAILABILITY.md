# Data availability / 资料缺口

实机读出与谱标定仍缺。主入口复算可脱离参考曲线运行的单音和脉冲滤波块。

Shot-resolved readouts and spectral calibration are missing. The runnable entry point covers the single-tone and pulsed filter blocks with self-contained inputs.
