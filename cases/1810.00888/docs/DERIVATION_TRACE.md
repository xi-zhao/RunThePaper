# Derivation trace

## PXP 与精确疤痕态

EQ001 从 Rydberg blockade 得到 H=sum_j P_(j-1) X_j P_(j+1)。代码先枚举无相邻激发的完整约束基，再显式构造 Hermitian Hamiltonian。

EQ002 按论文给出的 B、C 矩阵和边界向量逐配置收缩，得到周期与开边界精确 MPS。代码不读取作者波函数数组。四个 Gamma 态均直接验证 H psi = E psi。

EQ003 从补充材料的有限长度闭式式子计算局域 X 期望，并用完整基 MPS 收缩交叉检查。两条独立路线在 L=18 的最大差小于 1.84e-15。

## 近似疤痕塔

EQ004 与 EQ006 分别按打印的 bond-2 和 bond-3 矩阵构造 Xi 与 Upsilon 态，再做平移对称投影。每个变分态与独立精确对角化谱逐态比较。

EQ005 从 Z2 态反复作用 H+ 并归一化，构造恰好 L+1 个 FSA 态。零能简并处比较整个精确子空间权重，避免依赖任意本征基选择。

EQ008 在完整 Xi1–Xi13 非正交子空间中构造 H_eff 和 Gram 矩阵 B，求解广义本征问题。

## 纠缠熵

EQ007 将稀疏全链态重排为左右半链振幅矩阵，通过奇异值计算 Schmidt 概率和 S=-sum p log p。每组概率都验证归一化。
