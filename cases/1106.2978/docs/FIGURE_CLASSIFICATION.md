# Figure classification

`Main Fig. 1` carries no plotted observable or numerical axis, so reproducing
its pixels would add no scientific evidence.  It is excluded as schematic
context.

`Main Fig. 2` is the only numerical figure.  Panel (a), panel (b)'s main axes,
and panel (b)'s inset are separate targets because they test three different
physical regimes: spatial NESS structure, transport scaling, and insulating
decay.  All anisotropies, bath couplings and analytical overlays named by the
caption are included.
