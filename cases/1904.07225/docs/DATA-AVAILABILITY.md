# Data availability / 资料可用性

这里的 Brier 分数评估公开读出的预测。原 SSIM 倍数仍需同期逐次地图和制图设置。

The held-out Brier score tests prediction on public readouts. Historical per-trial maps and settings are required to re-evaluate the original SSIM ratios.
