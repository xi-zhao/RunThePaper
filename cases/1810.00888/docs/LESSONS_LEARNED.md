# Lessons learned

## New Failure Modes

1. 光谱 overlap 不能一律取全局最大值；必须先理解论文对“对应疤痕态”的物理配对规则。
2. 简并子空间中的单个本征向量不是不变量；比较必须使用投影到整个简并子空间的权重。
3. 数值 runner 不应导入 Matplotlib。首次隔离运行正确拦截了字体发现子进程，随后把数值与渲染拆成单向架构。

## Reusable Checks Or Tools

4. 原图可以服务于冻结后的 RenderContract，但不能成为数值生成数据源。
5. 论文错误判断必须比“曲线不一致”更严格：先排除实现、基选择、参数舍入和算力问题，再交给 fresh-context 评审。
6. “Phase 1 已冻结”不能只靠布尔字段。必须保存原始清单和哈希；若系统需要规范化 ID，只允许显式双射改名，并逐字段证明科学内容未改变。
