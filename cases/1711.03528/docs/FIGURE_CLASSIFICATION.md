# Figure Classification

| Paper target | Classification | Decision | Reason |
| --- | --- | --- | --- |
| Fig. 1 model graph | numerical model structure | reproduce | It is generated from the Hamiltonian acting on the constrained basis. |
| Fig. 2 entanglement dynamics | numerical simulation | reproduce locally | Paper uses iTEBD; local case uses finite-size exact evolution to check the same features. |
| Fig. 3 scar tower / FSA / participation ratio | numerical simulation | reproduce locally | This is the central numerical evidence for many-body scars. |
| Fig. 4 level statistics | numerical simulation | reproduce partially | It requires symmetry resolution and unfolding for paper-level agreement; local run checks the trend only. |
| Rydberg experiment referenced in text | external experiment | exclude | The case focuses on numerical reproduction, not experimental reconstruction. |

Acceptance is based on numerical features, not visual styling. A plot can look different while still passing if the same physical quantity shows the same trend.
