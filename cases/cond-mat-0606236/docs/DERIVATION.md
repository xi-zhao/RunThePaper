# Luttinger 突变：原文解析结果核验

固定 cond-mat/0606236v2；期刊题名不同，DOI为10.1103/PhysRevLett.97.156403。源包只有TeX与参考文献，无原始数值图。这篇不能以“重画原图”来衡量完成率。

自由初态、t=0骤开相互作用。先用 B(φ)双曲Bogoliubov变换把两模演化拆成相反频率的相位，再变换回来，得到原文 f=cos(v|q|t)−i cosh(2φq)sin(v|q|t)、g*=−i sinh(2φq)sin(v|q|t)。|f|²−|g|²=1是正则对易关系的独立检查。数值矩阵指数直接算同一两模生成元，与公式比较。

对指数UV正规化，令 γ=sinh(2φ0)，γq²=γ²exp(−|q|R0)。一粒子关联与自由关联的比值满足

log(C/C0)=−γ² Σ(n≥1) zⁿ/n [1−cos(2πnx/L)][1−cos(4πnvt/L)]，z=exp(−2πR0/L)。

由Σzⁿ/n=−log(1−z)可独立求和：记A(x)=1/2 log[(1−2zcos(2πx/L)+z²)/(1−z)²]，上式为−γ²[A(x)+A(2vt)−A(x+2vt)/2−A(x−2vt)/2]。因此有限环以L/(2v)复现。只在各弦长≫R0时才把A换成log[d(x)/R0]，得到原文渐近表达式；不在初始时刻或光锥边缘误用奇异的渐近式。

L→∞后A(x)=1/2 log(1+x²/R0²)。长时C/C0→[1+x²/R0²]^(−γ²/2)，远距异常指数γ²，异于平衡基态2sinh²φ。数值用直接q积分与闭式比较，并检查远距局部斜率；有限环不能先取t→∞充当热力学极限。

密度关联由q加权模和求得，几何级数Σ(n≥1) nzⁿ=z/(1−z)²的求和公式导出相同的x±2vt结构和原文系数1+γ²。GGE以n(q)=sinh²φq固定模式占据，去相位后给相同两点稳态关联；不声称所有高阶关联或整个密度矩阵热化。

有限温度将模积分乘coth(ℏvFq/2T)，独立积分与Gamma函数乘积求和对照。R0≪相关长度的渐近极限化成原文sinh替换，不能在任意UV尺度直接把渐近式当精确恒等式。

最初在x=100、2vt=500、T=.1的振荡积分中，自适应积分器低估误差，产生1.36×10⁻⁶差别并触发既定10⁻⁶判据。加入显式积分分段并提高积分精度后重算；不改原模型，也不放宽已失败的判据，失败实验保留。

计算用无量纲控制参数φ=.2,.5,1、R0=1、L=400、v=1，只是检验这些解析式的多参数取值，均非作者原图参数。原文未给实测实验数据；实验建议不是已完成的实验主张，不要求复现实验。
