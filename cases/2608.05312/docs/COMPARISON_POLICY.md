# Source comparison policy

These boards use limited excerpts from [Unidirectional Dark-to-Bright Rescue in Cavity-Coupled Quantum Transport](https://arxiv.org/abs/2608.05312) only to validate scientific structure and declared numerical regions. The independent result is generated from the published equations or method. The case does not redistribute standalone source panels, the paper PDF, author arrays, or digitized point sets. Pixel similarity is not treated as author-data-level equivalence.
