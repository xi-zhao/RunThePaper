# Derivation Trace

Use this file for formula-heavy papers. Every implemented equation should map
back to a source equation or an explicit derivation step.

## Formula Lane Rule

Every formula used by numerical code must have:

- a card in `EQUATION_CARDS.json`;
- a human-readable derivation in this file;
- a formula gate result in `outputs/checks/formula_verification.json`;
- a code pointer, or a note that it is not used in code.

Do not open a numerical target until its formula dependencies are traceable and
the formula gate is not closed.

## Conventions

Use the basis `(up, down)` and
`rho=(I+x sigma_x+y sigma_y+z sigma_z)/2`, so `z=rho_up,up-rho_down,down`.
Set `Omega=1` after the symbolic derivation.  Then every printed temperature is
`gamma'=gamma/Omega`; physical time and the main-figure coordinate satisfy
`tau=gamma_f t=gamma_f' Omega t`.

## EQ001 - driven-qubit GKSL generator

The theory figures and all later formulas follow the Supplemental 4x4 matrix.
With `sigma_-=|down><up|`, `P_up=|up><up|`, that matrix is generated by

```text
H = Omega sigma_x / 2
C_decay = sqrt(2 alpha gamma) sigma_-
C_dephase = sqrt(2 (1-alpha) gamma) P_up.
```

The standard identity
`DC=C rho C^dagger-{C^dagger C,rho}/2` gives exactly the Supplemental
4x4 generator.  Cyclicity of trace cancels every term in `Tr dot(rho)`.

There is an internal source discrepancy: Main Eqs. (1)-(2) print the same
standard dissipator but rates `alpha gamma` and `(1-alpha) gamma`, without the
factor two.  Expanding those literal main-text equations gives

```text
dot y = -(gamma/2) y - Omega z
dot z =  Omega y - alpha gamma (1+z),
```

which is the Supplemental model with `gamma` replaced by `gamma/2`.  Therefore
the conflict changes the temperature axis of every plotted curve by exactly a
factor of two.  The runner implements both paths: the Supplemental/figure path
generates the reproduction, while the literal-main path is a falsification
comparator and cannot silently replace it.

The sentence in the experimental paragraph that writes `H=Omega sigma_x`
differs by a factor of two from Main Eq. (1), all Supplemental equations, and
the standard Rabi-frequency convention.  The mutually consistent equations,
not the isolated prose sentence, define the numerical model.  This discrepancy
is retained for independent falsification review.

## EQ002 - affine Bloch dynamics

Insert the component form

```text
rho = [[(1+z)/2, (x-i y)/2],
       [(x+i y)/2, (1-z)/2]]
```

into the figure-consistent EQ001 and compare matrix entries.  The coherent term rotates the `y-z`
plane: `dot y|H=-Omega z`, `dot z|H=Omega y`.  Decay contributes
`(-alpha gamma x/2, -alpha gamma y/2, -alpha gamma(1+z))`; the printed
dephasing convention contributes the remaining transverse damping and the
remaining factor needed to obtain

```text
dot x = -gamma x
dot y = -gamma y - Omega z
dot z =  Omega y - 2 alpha gamma (1+z).
```

For `r2=(y,z)` this is `dot r2=A r2+b`, with

```text
A = [[-gamma, -Omega], [Omega, -2 alpha gamma]]
b = [0, -2 alpha gamma].
```

## EQ003 - steady state and ellipse

Solve `A r*= -b`.  Dividing by `Omega` and writing `gamma'=gamma/Omega`
gives

```text
y* = 2 alpha gamma' / (1 + 2 alpha gamma'^2)
z* = -2 alpha gamma'^2 / (1 + 2 alpha gamma'^2).
```

Consequently `z*=-gamma' y*`.  Substitution and collection of powers gives

```text
(sqrt(2/alpha) y*)^2 + (2 z* + 1)^2 = 1,
```

the right half of the printed ellipse.  The implementation evaluates the
closed form and independently checks `A r*+b` using a linear solve.

## EQ004 - rates, modes, and bifurcation

The characteristic polynomial of `A/Omega` is

```text
lambda_bar^2 + gamma'(1+2 alpha) lambda_bar
  + (2 alpha gamma'^2 + 1) = 0.
```

Dividing its roots by `gamma=gamma' Omega` yields

```text
lambda_plus/gamma  = -(alpha+1/2 + s)  # fast above bifurcation
lambda_minus/gamma = -(alpha+1/2 - s)  # slow above bifurcation
s = sqrt((alpha-1/2)^2 - 1/gamma'^2).
```

The discriminant changes sign at
`gamma'_b=1/abs(alpha-1/2)`.  Below that point the conjugate pair has equal
real parts; above it the fast and slow real rates separate.  The decoupled
mode is `lambda_x/gamma=-1`.

## EQ005 - slow amplitude and strong-effect root

For fixed final temperature, expand the initial displacement in the two right
modes.  Supplemental Eq. (11) fixes one particular normalization and therefore
the vertical scale of Main Fig. 2 right.  A coefficient by itself is not
normalization invariant; its zero and the product `a_n v_n` are.

Setting the Supplemental `a_-` numerator to zero gives

```text
gamma'_i,SME = gamma'_f * (
    alpha - 1/2 - sqrt((alpha-1/2)^2 - 1/gamma_f'^2)
).
```

At `alpha=0.94`, `gamma'_f=15`, this is `0.07619742787996348`.  The code checks
the same root in two ways: direct evaluation of Supplemental Eq. (11), and a
dual-eigenvector projection of `r_ss(gamma'_i)-r_ss(gamma'_f)`.

## EQ006 - exact dynamics and crossing observables

Subtract the final fixed point from the affine equation:

```text
delta_dot = A_f delta
delta(t) = exp(A_f t) delta(0)
delta(0) = r_ss(gamma'_i)-r_ss(gamma'_f).
```

Thus `d_ss(t)=norm(delta(t),2)`.  For a cold/hot pair, a nontrivial root of
`d_C(t)-d_H(t)` is the crossing time.  After bracketing the first sign change,
Brent's method finds the root.  A bounded scalar maximization then finds
`max_{t>=t_cross}(d_H-d_C)`.  An independent 4x4 density-matrix propagator
must give the same Bloch coordinates and distances.

## EQ007 - direct-preparation mixture

The steady state has Bloch radius `p=sqrt(y*^2+z*^2)` and polar angle
`theta=atan2(z*,y*)=-atan(gamma')`.  Using EQ003 gives the printed closed form

```text
p = 2 alpha gamma' sqrt(1+gamma'^2)/(1+2 alpha gamma'^2).
```

A qubit with Bloch vector of radius `p` along the `-theta` direction is the
mixture of the two antipodal pure states with weights `(1-p)/2` and `(1+p)/2`.
This verifies the preparation logic, but it does not reconstruct the missing
Main Fig. 5 experimental counts.

## EQ008 - literal-main falsification path

EQ008 preserves Main Eqs. (1)-(2) exactly as printed.  The only difference from
EQ001 is the absent factor two in both collapse rates.  Direct operator
expansion, a separately assembled Liouvillian, and the steady-state identity

```text
r_ss,literal(gamma') = r_ss,supplement(gamma'/2)
```

make the discrepancy independently testable.  It is not a floating-point,
eigenvector-normalization, or plotting issue.  Until a fresh-context reviewer
checks the complete paper inventory and alternative conventions, the case
classifies this as `inconclusive`, not as a confirmed paper error.
