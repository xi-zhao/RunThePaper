# Data availability / 资料缺口

逐次计数、实际控制和绝对谱幅校准缺失。公开入口复跑 DPSS 集中度和独立合成谱估计。

Shot counts, actual control waveforms and absolute spectral calibration are missing. The public entry point reruns DPSS concentration and spectral estimation on synthetic data.
