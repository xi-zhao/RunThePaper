# BLP：从约定到计算

锚定 arXiv:0908.0238v2（2010-01-05），不是 PDF 自动编译日期2018年。原文图1a/b、图2以及正文的中心自旋模型均纳入；期刊版与修订预印本逐式对齐仍待核对。

洛伦兹谱引起 G''+(λ−iΔ)G'+γ₀λG/2=0，G(0)=1，G'(0)=0。取 λ=1、γ₀=.01，与原文弱耦合一致。相位/Lamb shift不改变这篇要比较的迹距离；不以它改变主方程的表象。激发/基态对距离 D=|G|²，σ=dD/dt，图1纵轴除以γ₀。

任意两个初态的 Bloch 向量差除以2记作r，D(t)=sqrt(|G|⁴r_z²+|G|²(r_x²+r_y²))。最大化可取反向纯态（线性缩放扩大距离）；轴对称使问题只剩 r_z²∈[0,1]。因此在原文1000随机态对之外，再用1001角度网格检验原文给出的极值。实际判断限于所算参数与网格，不把采样当一般性极值定理。

σ的正区间由根定位后计算端点增量，避免积分阈值造成小量误差；[0,30]、dt=.002与[0,60]、dt=.001比较。独立解法为二变量 pseudomode ODE，不读取原图。随机态使用明确新种子，原文散点只比较分布范围，不要求逐点重合。

第二模型 H=AσzΣσz(k)，最大混合浴态的直接有限维迹为2⁻ᴺΣ exp(−2iAtΣs_k)=cosᴺ(2At)，与推导结果比较。|cos|ᴺ每次回升贡献1，有无限次回升，所以原文测度发散；有限时间图只是这项解析结论的示例。图1a/b与图2之外，不捏造中心自旋“原图”。
