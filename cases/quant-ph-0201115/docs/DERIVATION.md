# Zeno 子空间：解析结论与原例核验

原文：quant-ph/0201115v2。唯一原图是 Hilbert 子空间的海龟示意，不存在数值原图。检查其“同一谱投影内可以运动、不同谱投影间被抑制”的含义；本报告计算图明确标为核验图，不计原图像素复现。

设 Hmeas=Σηn Pn、Hdiag=ΣPn H Pn。有限维、时间不变且不同ηn有非零间隔时，在测量相互作用表象，非对角项获得 exp[iK(ηm−ηn)t]。分部积分的振荡积分给 O(1/K)抑制，剩余演化由 Hdiag生成。这是本文核心的平均化/绝热论证。在实验室表象应比较 e^[-i(H+KHmeas)t] 与 e^[-i(Hdiag+KHmeas)t]，保留随K振荡的相位。若把原文的lim符号读成所有扇区上不去相位的普通算符极限，则通常不存在；这不影响扇区概率守恒和Zeno动力学的物理结论。

独立静态核验：令 Q(X)=ΣPn X Pn，则 Q²=Q、Q(H)=Hdiag，且[Hdiag,Pn]=0。每次投影之间演化 dt 的对角块为 Pn−iPnHPn dt+O(dt²)；N次乘积（dt=t/N）趋于 exp(−iHdiag t)。无限维时需自伴性、域和极限存在等条件，有限维模拟不证明无限维的一般定理。

原文四例均检查：(1) 三能级谱为0,±sqrt(K²+Ω²)，求|1>投影得文中精确生存概率；(2) K'≫K≫Ω时强耦合先隔离|3>±|4>，|1>,|2>扇区内恢复Ω振荡；(3) 两个Λ原子+有损腔的五个暗态，直接作用Hmeas为零，用三个光子截断检查零空间维数及边界假暗态；(4) 结构化连续谱的三维有效非厄米H，用矩阵指数与独立ODE核验衰减抑制，并核对真空参数所需约10²⁰/s强度。数值选定Ω=1等只是原模型的核验参数，不是作者未提供的原图参数。

例3的腔衰减是无跳跃有效描述，暗态本身不衰减；不将非厄米生成元当Hermitian绝热定理直接套用。零空间分析与投影弱Hamiltonian的说明分开保留。例4也不把无跳跃概率重新归一后伪装成无衰减。

首次核验失败来自我们的显式ODE自适应步长：快速衰减分量小于绝对容差后，步长不再受它约束，晚时出现约8.6×10⁻⁹稳定性误差；矩阵指数与独立谱分解在约7.1×10⁻¹⁵内一致。减小容差有改善但不足以单独解决快慢尺度；将最大内部步长限制为.02后重新核验，保留原来的10⁻⁹判据和失败回执。这个修复不改变模型或纸面结论。
