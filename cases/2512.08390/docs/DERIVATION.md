# 高斯展开、最优解与评分

补充材料 S1 给出体相校正 $p=g-1$、以最近 3D-RISM 网格值为振幅和阈值。用 $G_i=A_i\phi_{\sigma^2}(r-q_i)$，其中 $\phi$ 为归一化三维高斯。QUBO 对角元为 $\int G_i^2-2\int pG_i$，非对角元为 $\int G_iG_j$。非对角积分在无穷域为 $A_iA_j(4\pi\sigma^2)^{-3/2}\exp[-\|q_i-q_j\|^2/(4\sigma^2)]$，成本对其加倍。用合成密度分别做可分积分、直接三维 Simpson 和无穷域闭式积分。对两组完整矩阵穷举，再以 MILP 中的乘积辅助变量独立复核。令 $s_i=1-2x_i$，检查 Ising 常数、局部场及相互作用在每个比特串上的总能量。

高斯重叠使近距离同时占据付出更高成本。只有额外假设线性收益界或引入硬排斥约束，才保证最小间距。合成粗网格的最优解已经出现 1.05 Å 的两处占据，说明需单独确认真实样本的间距。

在覆盖率分子中，按前文定义应数至少匹配一个预测水的晶体水。若按后一行把多个合格预测水分别计数，3 个晶体水各有 2 个预测水时得到 2，超出声明区间。式 (5) 的内分母字面为 $n$。3 个相隔足够远且完全命中的晶体水给 $1/3$。按簇内 $N_i$ 平均才给 1。式 (6) 以预测水数 $m$ 枚举按晶体水定义的簇，$m>n$ 时出现未定义项。式 (7) 可按每个命中晶体水取最大分数，未命中记 0。应取得原评分代码和匹配约定后再核对真实系统的图 5–7 及补图。
