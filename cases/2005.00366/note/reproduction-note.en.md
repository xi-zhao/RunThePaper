# Parallel robust trapped-ion gates

At the nominal five-ion settings, strict closure and first-order robustness exclude the literal +π/4 phase. The −3π/4 phase gives a gate equivalent up to a global phase. The strict PM grid covers 2,173 cells. Independent computations include 4–20 ion chains and 20-ion parallel gates. [Paper](https://doi.org/10.1002/qute.202000044)
