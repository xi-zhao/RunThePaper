# Source-to-implementation correspondence (fixed arXiv v2)

Sources: source/fixed.pdf and archive; extracted reference/original/main.tex is byte-exact.

Open chain, alternating layers (0,1),(2,3),... then (1,2),(3,4),... . One time index is one layer as Eq. (6), while the prose calls a two-layer pair a period. Edges imply L/2-1 gates in the second layer; the text saying L/2 in both is not literally compatible with open boundaries. Initial state is |+>^L. Each scheduled gate independently has probability p of a measurement BEFORE its independent unitary. Model 1 measures Z_i then Z_{i+1}; model 2 measures Z_i Z_{i+1}.

Clifford generation enumerates the complete order-720 binary symplectic group generated by H_0,H_1,S_0,S_1,CNOT. All 16 Pauli lifts of a symplectic element differ only in signs, so uniform sampling of this quotient is exact for entanglement of trajectories with outcome-independent gate sampling. This is NOT an approximation of a finite-depth random word distribution. Binary Pauli supports retain a maximal commuting subgroup. Measurement replaces one anticommuting generator with the measured Pauli and eliminates anticommutation in the others. Deterministic measurements change only possible signs. Entropy is rank_GF2(M_A)-|A|: the subgroup acting only on the complement has dimension L-rank(M_A), and purity of the reduced stabilizer projector gives this formula. All Rényi indices coincide because the reduced spectrum is flat.

Independent check: explicit complex 2^L wavefunctions, Born-weighted projectors, and partial-trace purity, after every gate and at every cut. All 720 gate actions additionally checked via Pauli conjugation. Criteria before full generation: matrix errors <1e-12, entropy error <1e-10 bits, norm error <1e-11.

Steady values are cluster means per independent trajectory using both layer parities, at t=399,400,419,420,...,599,600. SEM is across trajectory means; no falsely independent count of correlated times. Original says steady-state ensemble of 100, but does not specify precisely how time/parity was averaged. Therefore retain both parity outputs and test the difference explicitly. A1 has exactly zero entropy when a cut does not cross a last-layer gate and the Haar two-qubit entropy when it does. Averaging parities is a documented inferred convention needed to compare its smooth Fig. 2(a); it is not attributed to author code.

Numerical comparison criterion: full-range residuals, Monte Carlo standard errors and calibrated vector-reading error are reported. There is no universal pixel or percent pass threshold. Exponents require finite-size/time and fit-window sensitivity; a curve at smaller sizes does not establish asymptotic exponents. Original plots are reference-only, never generation inputs.
