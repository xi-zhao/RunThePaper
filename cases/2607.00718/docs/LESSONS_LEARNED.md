# Lessons Learned

## Case Summary

- PaperID: `2607.00718`.
- Status: terminal full-paper scientific reproduction.
- Scope: 23/23 numerical panels, 5/5 claims resolved.
- Main finding: four claims verified; the published quantitative Figure S1
  cutoff claim rejected.
- Other evidence gap: released Figure 4 transmission arrays belong to an
  earlier manuscript version.
- Additional source correction: Figure S3's visible curves are normalized
  enhancements although its printed axis says absolute energy.

## What Worked

- Model one reusable two-mode Gaussian system before implementing figures.
- Derive and test formula objects before allowing numerical generation.
- Generate arrays independently, then load author data or source images only
  for comparison.
- Use two mathematically independent numerical lanes for disputed dynamics:
  exact Gaussian moments and bounded finite-Fock Liouvillian evolution.
- Treat a supported rejection as a scientific outcome, not a failed agent run.

## What Was Difficult

- The blog, arXiv source, PRL article, and Zenodo record represent different
  evidence versions.
- The main-text transmission TeX contains a brace typo resolved only by the
  supplemental scattering derivation.
- The supplement admits finite-Hilbert truncation for S1 but omits its cutoff
  and convergence study.
- Figure S3's printed observable and plotted intercepts cannot both be true;
  resolving this required carrying absolute and normalized formula arrays in
  parallel before looking at the source image.
- The original case finalizer omitted two terminal gates, leaving a completed
  campaign looking active until those gates were explicitly generated.

## Generalized Experience

| Lesson | Why it generalizes | Recommendation |
| --- | --- | --- |
| Released data need version identity | official data may still be stale | compare titles, formulas, numbering, and numerical landmarks |
| Exact model closure outranks an arbitrary truncation | unconverged cutoffs can mimic published plots | derive the cutoff-free reference first and demand convergence |
| Axis labels are scientific claims | a correct-looking label can contradict every plotted curve | compute dimensions, limits, intercepts, and endpoints before visual scoring |
| Rejected claims can close scientific scope | reproduction includes finding paper errors | separate execution success from claim adjudication |
| Terminal state must be generated by code | session-only cleanup is not reproducible | finalizers must own every completion gate and lifecycle refresh |

## New Failure Modes

| Failure mode | Evidence | Detection |
| --- | --- | --- |
| `stale_author_dataset` | Figure 4 released peak `10.067` versus final formula `27.308` | compare version identity and formula landmarks |
| `undisclosed_unconverged_fock_cutoff` | S1 exact peak `59.9715`, cutoff-10 peak `3.7532`, source near `4` | require cutoff disclosure and successive-cutoff convergence |
| `source_figure_semantics_mismatch` | S3 absolute baselines `1.5242`, `1.0412`, `0.1176` versus three visible unit intercepts | generate competing formula observables, test limits, then use the source only to adjudicate |
| `scientific_discrepancy_misrouted_as_retry` | an unchanged TS01 run initially remained in the retry loop | distinguish executable pass from paper-claim verdict |
| `terminal_gate_not_materialized` | status stayed actionable after finalization | make the finalizer generate scientific-scope and formula gates |
