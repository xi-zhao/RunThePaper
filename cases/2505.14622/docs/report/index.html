小差异影响什么

  • 短时浅谷：距离下降约 0.14%，不改变已核对的 strong PME 和全程加速结果。
  • 参数舍入：重建参数与印刷值相差不超过 0.005，会改变细小曲线位置；两套结果均保留。
  • 速度单位：正文与公开绘图代码相差 2 倍，只改变速度色标，不改变轨迹。
展开浅谷与绘图采样的具体证据

按文中声明的驻态重建参数，初始距离导数为 −0.375；距离从 0.5 降至 0.4993150，最低点在 t≈0.0037587。负斜率可直接由方程求得，故浅谷不是积分误差制造的假象。

公开 notebook采用 0–3 上的 300 个输出采样点，间隔约 0.01003，跳过了这个极短时浅谷。这里是绘图输出间隔，不是自适应积分器的内部步长。它解释了为何图上难以看见浅谷；作者写作时的具体依据尚未确认。
