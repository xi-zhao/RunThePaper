# Rerun / 复算

Public circuit-layout data were rescored and nine training losses evaluated. The best mean selection error on the paired public subset is 7.60%, against 12.85% for Mapomatic.

Use the [code instructions](../code/README.md). The default stages run into a new directory.

- `haar.py`

The default entry calculates the Haar-fidelity controls. Rebuilding the ranking features requires the published Zenodo records. The feature assembly and rank-loss scripts preserve the recorded split settings.
