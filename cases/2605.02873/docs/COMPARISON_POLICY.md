# Source comparison policy

These boards use limited excerpts from [Fixed-detector tilt--defocus sensing by upstream source coding in a time-reversed Young interferometer](https://arxiv.org/abs/2605.02873v1) only to validate scientific structure and declared numerical regions. The independent result is generated from the published equations or method. The case does not redistribute standalone source panels, the paper PDF, author arrays, or digitized point sets. Pixel similarity is not treated as author-data-level equivalence.
