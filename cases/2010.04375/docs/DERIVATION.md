# QC22 位移和频率输入

有符号驱动为 $u(t)$。单模条件位移 $\alpha=-i\eta\int_0^T u(t)e^{-i\theta(t)}dt/2$。热态特征函数给 $P_1=[1-\exp(-2(2\bar n+1)|\alpha|^2)]/2$。两个自旋分支的二阶运动几何相位相同，读出只需差分位移。

若 $\theta(t)=2\pi t\beta(t)$，线性核为 $t u(t)$，与式 (4) 相符。若 $\beta(t)$ 是瞬时频差，则 $\theta(t)=2\pi\int_0^t\beta(s)ds$，交换积分后核为 $\int_s^T u(t)dt$。闭合脉冲的非零频率响应为 $\widetilde u(f)/(2\pi i f)$。两式对静态偏差等价，对时变输入一般不同。用分段 Gauss 积分和多相位直接位移复核导数，用 PDF 的图 2b 理论曲线验证相对形状。两法均允许独立的非负整体尺度和常背景。

DPSS 按补充材料 $NW=1$ 取零阶并以峰值归一，有符号余弦与翻转合并。奇阶包络反对称，面积为零。平方脉冲在精确分段端点积分。合成谱使用声明的频带和相位翻转数，按 S16–S19 进行非负一阶差分惩罚和奇偶交叉验证。每折五次重采样，使用新种子和自定的噪声、$eta$。每个解以 KKT 条件检查。

用原文印刷的峰高和带宽计算 $\beta=\sqrt{2S\Delta f}$，对峰高误差线性传播。式 (S4) 的响应在固定波形下随 $T^4$ 增大，阈值随 $T^{-2}$。式 (S6) 对整个频带积分，阈值随 $T^{-3/2}$。实机底噪和额外模态不在此缩放里。
