# 三模关联：已定位截断风险，尚未恢复原始整条曲线

所有原条件保持E=(0,.12,0)、α=.012、Γ=.1、F=.1。完整稳态计算仍给g₂(0)=.34699064724；正文.28与EPS零延迟.452214为两个不同的原文数值目标。此次用完整时间曲线约束解释，没有仅凭零延迟接近就宣布对齐。

Γ与F分别取原值的1/2、1、2，9组均完成相邻截断及尾概率检查。它们没有恢复整条源曲线，最小曲线RMSE约.1153，远大于读图尺度。有限制备时间也检验到64个损耗寿命：6寿命时零延迟.44091接近原图，但完整曲线RMSE仍约.130，且占据比稳态低5.53%；64寿命时回到.34699064724，排除了用这一近似接近替代稳态对齐。

不同方法的非均匀Fock截断给出具体风险：信号/闲频最多2光子时，泵浦截止2、3、4的弱驱动极限分别.19170948、.20211786、.25639208。泵浦截止3时，F=.003的边界占据仅1.61e−11，但归一化g₂仍偏离正确弱驱动极限约21%。原因是两个信号光子需要两次成对散射，F⁸的首阶阶乘矩包含最高4个泵浦光子的中间态；绝对人口很小不保证归一化关联误差小。

这确实定位了一种实现错误机制，但这些低截止版本均未恢复原整条曲线，不能据此认定作者采用了该截止，也没有用较接近的坏截断替换已收敛结果。原正Gaussian曲线、三模曲线与高占据条件仍是我们的未完成对齐，未列作者信息硬阻塞。
