## 不重跑的边界

旧97篇不执行求解器、Notebook、训练、案例测试或科学检查器，也不修复旧代码。
允许读取原文和已有文件、核对版本、计算已存数组之间的误差、做描述统计和重绘已有数据。
重新读取或比较不是历史科研执行；归档未保存的信息保持未知，不填成0或全自主。

只有3篇新增开展新的科学运行。它们先在PRAgent工作区完成来源快照、范围冻结、
实现、执行和核验；再由PRAgent的 `publish_manifest.json` 投影到本仓库。
不得直接往 `cases/` 填空壳或手改目录状态来增加数量。
本PR不触发Actions、付费模型或任何科学计算，不修改97篇成果及旧审计。

## 论文问题与数据

主问题：大量真实论文任务留下了哪些成果？它们在方法、条件、数值结果与核查依据上达到什么程度？

- **RQ1 成果范围：** 解析推导、数值求解、统计、算法各留下什么实际产物？
- **RQ2 条件与一致性：** 原物理条件、等价计算、缩尺度、部分范围、代理实现分别做到哪里？
- **RQ3 证据与限制：** 哪些有数组、误差、收敛、独立方法或版本记录，哪些只有报告？
- **RQ4 分歧处理：** 既有记录能否区分自身缺陷、原文条件不明、参考版本问题和原文疑错？

只需论文级表和逐结果证据表；使用
[RESULT_RECORD_TEMPLATE.json](RESULT_RECORD_TEMPLATE.json) 录入真实来源，不使用模板数值作结果。
子图、独立表格结果或解析命题是定位单位；支持性检查不重复增加成果数。
每篇保留已知未完成对象。原文范围没有核齐时不报告整篇百分比。
不复用旧 `reproduction_degree` 混合分，不以像素相似、文件数量或顶层 `passed` 代替科学结果。

成果属性（条件、范围、相符/不符）与证据属性（报告/原文件/独立检查）分别统计。
误差必须有原单位、比较对象和适用范围；不把不同物理量的误差平均成总分。
未知、未达到和有依据支持分开；原文疑点不等于确认勘误，反驳证据也不是复现失败。
有效的精确子空间约化不是缩小物理体系；不同随机种子本身不是失败。
