# 非厄米 skin effect 与 chiral damping：从论文到计算

数值源固定为 arXiv:1904.08432v2（31 Oct 2019），期刊书目信息 PRL123,170401。
期刊全文入口未取到，不能声称已逐字核对最终排版；v2 的正文和补充推导已核对。
第一次独立生成前没有读取作者绘图矢量坐标或数值实现。

本论文 Lindblad 定义是 `2L rho Ldagger-{Ldagger L,rho}`，与标准 GKSL 的速率差2倍。
记 `Delta_ij=Tr(c_i^dagger c_j rho)`，用费米反对易关系推得
`Delta_dot=X Delta+Delta Xdagger+2 Mg`，`X=i h^T-(Ml^T+Mg)`。
闭合来自二次 Hamiltonian 与线性 jump，不需要高斯初态假设。

模型I：`Ml=gl/2(I+sy)`、`Mg=gg/2(I-sy)`；
`Delta_s=gg/(gl+gg) I` 满足驻态方程。
偏离量 `D(t)=exp(Xt)D(0)exp(Xdagger t)`；完全填满初态使 `D(0)=I/2`（等速率）。
`ntilde_x=D_xA,xA+D_xB,xB`，正文整体指标为 `sqrt(mean(ntilde_x^2))`。
PBC 平移对称使每个胞元相同，Bloch 分解可用2x2矩阵逐 k 独立计算。

模型II 仅翻转 gain 中 i 的符号，故 `Mg=gg/2(I+sy)`。
等速率下 X 的耗散部为标量，没有 skin effect；
但 Delta_s 通常不是 I/2，需解连续 Lyapunov 方程，不能沿用模型I驻态。

OBC 光谱独立稳定解：设 a=t1-gamma/2>0、b=t1+gamma/2，
选实对角 D 满足 `D_Bx/D_Ax=sqrt(b/a)`、`D_A(x+1)=D_Bx`。
则 `D^-1(X+gamma I/2)D=i H_eff`，H_eff 是胞内跃迁 sqrt(ab)、胞间跃迁 t2 的厄米 SSH 链。
用厄米三对角求解保留有限链边缘态。D 可能极端病态，因此只用它推导光谱，
动力学始终对原始 X 作 expm，再以等间隔半群乘法传播正的初始差矩阵因子。
这避免将非正规矩阵的病态特征向量分解当作稳定时间演化算法。

有限尺寸边界：t1=t2、偶数胞元数的 PBC 网格恰含 k=pi，X 存在精确暗模。
因此 Delta_s 是驻态，但任意初态收敛到它的唯一性必须另核对；
全填满初态预计留下 `ntilde=1/(2L)`。正文热力学幂律和有限链极长时间不能混用。
判断该限制时需独立验证暗模残差与全 Fock 空间小系统演化，不能只靠数值小本征值。

独立核验：Jordan-Wigner 构建2胞元4站点的完整16维 Fock 空间，
直接从原始 H、L 构建256维 Liouvillian，对照相关矩阵约化；
再用直接 expm 对照 Bloch 解析传播、步长细化、稳定光谱和动力学取样。
重点检测转置、2倍速率、PBC/OBC、cell/site 计数和 RMS 归一化。

原图核验后的精确约定排查（独立 v1 计算已先冻结）：令 P 为归一化暗模的投影，
三种合法驻态相关矩阵为 `C0=.5(I-P)`、`Ch=.5I`、`C1=.5(I+P)`。
三者均满足驻态方程且谱在[0,1]；C0 的暗模占据0，C1 是全填满初态的实际有限链极限。
由于每胞元的 P 对角和为1/L，相对三者的密度偏离分别为
`nref_half+1/(2L)`、`nref_half`、`nref_half-1/(2L)`。
原图偏移的方向是比 Ch 参考曲线更高，故不能解释为已经扣除了全填满实际极限。
C0 参考能解释该差距；这说明图形与另一合法驻态约定相容，并不证明作者用了哪种求解器。
Fig3a 的周期链候选长度30/40/50/60/150逐一比较，L30最吻合；该长度仍明确标为推断。
