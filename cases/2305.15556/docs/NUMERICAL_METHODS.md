# Numerical Methods

## OAT 通道（T001–T004）

- 粒子数：`N=20`；时间 `tau in [0,pi/2]`，321 点。
- Husimi 网格：121×241；两幅曲面分别在 `tau=0` 和 `N^(-2/3)`。
- 求解：解析相位演化，3×3 纯态协方差 QFIM，实对称本征分解。
- 验收：闭式 QFI/最优轴、初末态谱、概率边界、本征残差。

## SU(4) 通道（T005–T006）

- 粒子数：`N=20`；四模对称空间维数 `C(23,3)=1771`。
- 时间：`tau in [0,pi/2]`，241 点，精确包含 `pi/4`。
- 求解：CSR 哈密顿量 + Krylov `expm_multiply`；每个时刻计算 15×15 QFIM。
- 输出：前八个本征值、J/K/E 子群上界、15 个代表系数、领先投影算符。
- 验收：态范数、正半定性、论文峰值/锚点、稀疏/稠密 parity、保真度 QFI。

## 数值风险

最重要的风险是把近简并当成精确简并，或者用源图挑选系数规范。实现以相对阈值
`1e-10` 定义领先空间，并将投影算符作为科学证据。完整运行只需数秒，无需 A100、
分片或 checkpoint。
