# Rerun / 复算

Compute held-pulse and discrete-time concentration using quadrature. The spectral block uses the same filter bank on synthetic lines, retaining the model-generated adaptive and Bayesian estimates separately from experimental reanalysis.

Use Python 3.13 and the [code instructions](../code/README.md). The entry point runs the following stages into a fresh directory.

- `generate.py concentration`
- `generate.py spectral`

The overview is drawn from the recorded independent outputs. [Curve data](../outputs/data/overview.json) · [Scientific assessment](../outputs/checks/completion_assessment.json)
