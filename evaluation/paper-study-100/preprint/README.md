## 可复算成果

Figure 1为重新设计并逐项核对的概念架构图；Figures 2-4由固定公开版本的数值数组重绘；Figure 5将历史结论覆盖率按本文100篇名单重新对齐，并展示存档的核验状态。数值图重绘没有运行原案例求解器，也没有复制作者原图。`build_evidence.py`读取公开Git对象，复算量子游走粒子数守恒残差和资源比例，保存输入哈希及结果摘要。物理模型、原始理论与源论文作者明确归属；报告贡献为实现、工作流与科研工件组织。

```bash
python build_evidence.py
python build_overview.py
python build_reason_audit.py
python build_diagnostic_followup.py
python build_obstacle_examples.py
bash build_report.sh
python package_arxiv.py
```

数值图环境沿用 `../manuscript/requirements.txt`。Figure 1保留已审阅的设计图；`build_figure1.py`使用 `reportlab==4.4.9`将原PNG无像素修改地封装为PDF。执行数据复算不会覆盖该设计。排版使用Pandoc和标准PDFLaTeX，没有本机系统字体、绝对文件路径或非标准期刊类依赖。打包工具在干净目录中解包并执行两次PDFLaTeX，检查每张引用图和100个队列身份。

## 阅读主线

先介绍PRAgent如何连接科学问题、实现与检查，随后用三个深入案例展示精度处理、物理表示和统计比较能力；总体覆盖图交代100篇项目的广度，诊断案例展示排查过程。通用的人机协作和评测边界集中在局限章节；每个案例保留影响其结论的具体限制。标题、摘要与投稿元数据从同一正文生成。

## 总体复现图口径

全图保留100篇，不设置来源分组。历史数值结论等权覆盖率为40.9%，有测量论文的逐篇平均为57.8%；3篇没有该项测量，保留缺失。两者均不表示整篇论文完成率。图中核验状态来自同一冻结版本中的案例评估文件，历史覆盖表不覆盖后续或更严格的验收结论。逐篇、逐结论、逐检查源数据及文件哈希保存在 `anc/overview_*`，随arXiv草稿源包提供。

## 复现障碍与诊断推理

正文保留整体复现程度图，撤下责任分类数量表。论文本身、Agent、算力和实验设备作为四个排查方向，不作为已验证的原因分布。三例分析分别展示原文能否唯一确定计算、实现是否覆盖所需科学对象、未完成计算是否有资源测量依据；逐例交代观察、已有排查、可支持的解释与仍需验证的内容。

这些案例是说明性选择，不代表全队列失败原因的分布。`anc/obstacle_examples.json`保存原始诊断、来源位置、文件哈希与推断边界；报告没有重跑其求解器。原有 `anc/reason_*` 和 `anc/diagnostic_followup_*` 保留记录来源，不能将其旧标签计数当作新的因果研究结果。四类排查标准见[分析框架说明](四类归因说明.md)。

旧责任映射移至 `qa/exploratory_attribution/`，明确标为已撤下的探索性分析，不进入正文或arXiv源包。全队列的缺失与状态冲突仍如实保留。

## 旧归因标签复查

[八案复查说明](诊断复查说明.md)给出每案具体障碍及尚待核验的证据。8个案例的44条旧标签均能定位到具体边界说明，其中3条已有更新的计算容量诊断、41条仍保留旧编码。因此不再把该计数写成“8个根因完全不明的科学失败”。这次核对没有执行新数值计算，也不宣称完成了独立科学归因。三份 `anc/diagnostic_followup_*` 文件随源包提供。
