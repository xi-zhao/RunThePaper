# Data availability / 资料缺口

公开入口复跑模型核查。原始条纹、加速度记录、优化波形及实验校准仍缺，标度因子差异保留。

The public entry point reruns the diagnostic model. Raw fringes, accelerometer records, optimized waveforms and calibrations are missing, and the scale-factor differences remain.

[Paper](https://doi.org/10.1038/s41467-023-43374-0) · [Preprint](https://arxiv.org/abs/2303.03683v3)

The publisher's Source Data link contains the processed XLSX required by the optional reanalysis script.
