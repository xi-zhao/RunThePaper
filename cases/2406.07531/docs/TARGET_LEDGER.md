## Shared causal diagnosis

- Direct cause: paper-exact material inputs are unavailable in the accessible
  main article/arXiv package.
- Root cause: `unresolved/open`. The current evidence cannot distinguish a
  publication omission from information in the inaccessible formal supplement.
- Code-fault status: `not_excluded`. Small-system algebra and an isolated
  method-validation run pass, but the periodic production path has not run.
- Next discriminating test: obtain and hash-freeze the legitimate supplement,
  bind every disclosed input to the run contract, then execute one converged
  material shard with an isolated attestation.

Code readiness means that the target has a configuration, target mapping, work
unit, stage graph, resource contract, checkpoint contract, expected outputs,
and fail-closed acceptance rules. It does not mean that material-specific data
exists or that the production code has been fully validated.
