# 非Bloch能带：中间两根与实际开链

原文1902.10958v2包含主文及补充材料。主文图1为能带稠密化示意、图2a为跃迁示意；数值目标保留图2b1–d2、图3a–e、图4a–d，及补充S4两幅根轨迹、S5b的Lee模型开链谱。其余补充图为几何/端点势示意，审查物理内容而不以重画计分。

把ψn=βⁿu代入原文实空间跃迁，得到R+=(t2−γ2/2)/β+t1+γ1/2+t3β，R−=t3/β+t1−γ1/2+(t2+γ2/2)β。E²=R+R−是四次β多项式。按模排序后只有|β2|=|β3|给连续开链带，任意两根等模不能代替它。补充边界行列式中的各主导项约为(βiβj)^L，只有两项模相同且可相消才产生稠密谱，构成这一选择的推导。

独立算法：令另一等模根β'=βexp(iθ)，消去E²后求四次方程，再把每个候选带回完整特征多项式，明确筛选中间两根。保留全部等模候选用于补充S4b对照。候选β按极角排列产生闭环并算R±的绕数；零能相图则另从R±各自的二次根排序计算，不用原图颜色也不从开链边态拟合。

在E=0处，若中间两根同属R+或R−、为共轭等模根，则有EP闭隙区；不同R的两根交换顺序定义相变边界。两最小根都属R−时w=1，分属两种时w=0；多项式降阶按补充说明保留β=0或∞的极限，不能少一根重新排序。

独立建立实空间开链矩阵求谱，与GBZ连续带比较。采用对角相似变换ψn→rⁿψn平衡非互易尺度，避免皮肤态的指数条件数被误认成物理效应；它不改变精确本征值。主文没有在图注标开链L，选择L=100并保留L=30,60,120及复端点势的收敛记录；明确报告这是我们的有限尺寸选择，不将其称为作者实际L。边界无关指有限端点改变下的渐近连续带，不包含把链重新连接成周期边界，且边界局域离群态可变化。
