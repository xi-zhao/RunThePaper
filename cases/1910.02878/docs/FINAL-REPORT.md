## 新解决的三个子问题

**1. 原证明更早的一步也需要限定范围。** 正文 Eq. (5)／补充 SIV 把全部有限开链谱的极限放进固定左端半无限谱。一个局部双带、左右端点不等价的链反驳了这个完整谱命题：有限链右端能级趋于 3，而左端半无限系统的谱始终离 3 至少 0.37882942。去掉胞内弱耦合时，更可精确分解成两端孤立态与相同二聚体；能量 3 对每个 N 都是本征值，却不属于左端半无限谱。

独立核对包括精确特征多项式、半无限算符的显式有界逆、常数相似变换后的厄米奇异算符。它说明完整谱需要同时处理两种端点，或把命题明确限定为去除孤立端态后的体谱。**这个例子没有非厄米趋肤效应，不是物理定理 II 的反例。** 一般块 Toeplitz 理论也区分两端的离散谱，见 [Koekenbier 与 Schulz-Baldes，2024，Section 3.1](https://ems.press/content/serial-article-files/48616)。该文只作通用数学参照，没有导入它的数值解来代替独立生成。

**2. 找到一个不依赖失效步骤的正面拓扑论证。** 对有限扭曲边界环，精确傅里叶分解使行列式等于 N 个相邻动量区间的乘积。绕一圈通量所得绕数正好是原 Bloch 绕数 W，而非 N 倍。开链与通量无关，绕数为零；所以从环连续切开必经过点隙闭合。真正混合的双带模型在 N=3、5、8 均核对了行列式恒等式，误差不超过 6.2e-15。

这个论证解决了 class A 的边界切割点隙转变；它本身不证明闭合发生在多小的端点耦合处，也不证明全部有限右本征态的广延局域化或所有对称类别。

**3. 正面谱敏感性已不只限于两个独立标量通道。** 新例子的胞间矩阵和胞内混合矩阵不对易，没有共同不变自旋子空间。半无限局域模可给出一个指数小的跨端矩阵耦合，使 E=i/5 成为有限链的精确本征值。

这里没有把病态矩阵的双精度本征值或小奇异值直接当结论。独立检查用精确有理数根隔离、Rouche 界及边界行列式主项支配，证明：**所有 N>=15 的未扰动谱，都避开以 i/5 为中心、半径 1e-5 的整个圆盘。** 同时给出端点耦合范数上界 K*rho^(N+1)，其中 K<93、rho<0.736。N=192 时，耦合范数上界为 1.89e-24，实际谱位移至少 1e-5，二者之比严格超过 5.30e18。计算出的约 1.92e-27 耦合更小，但这里采用较保守的有理数上界报告结论。
