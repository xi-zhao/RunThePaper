# Data availability / 资料缺口

原始 RB 和探测记录、实际实验约定以及原 Hessian 区间仍待核对。公开入口重算有限状态 RB 矩，GST 原计数沿用作者入口。

Original RB and detection records, laboratory conventions and the original Hessian intervals remain unresolved. The public entry point reruns finite-state RB moments; original GST counts are available from the authors.

[Paper](https://doi.org/10.1038/s41534-017-0052-0) · [Preprint](https://arxiv.org/abs/1706.03787)

The publisher's Supplementary Information and data-availability statement point to the released GST assets. The run records the fit results and uses the published files for the count inputs.
