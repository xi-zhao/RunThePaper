# RunThePaper 品牌叙事

这份文档维护 README、项目介绍和后续内容的共同定位。以项目方提出的
“可执行的科学史”为核心，使用定位画布、战略叙事和品牌消息体系的方法组织表达。
证据来自本仓库；受众与长期愿景由项目方提供。

## 定位与受众

**我们建设什么：** 一部可执行的科学史。围绕可识别的论文，把推导、方法、代码、
生成结果和验证证据组织成可以学习、运行和继续发展的研究案例，持续积累。
当前从物理学和量子科学出发。

**首先服务谁：** 想进入某个研究方向的研一学生，以及具备相应基础的本科生。
他们需要找到合适的起点，理解关键假设，完成第一次计算，并知道接下来可以问什么。
研究者、教师和评审者也可以用同一份材料核验、教学和扩展研究。
科学智能体是后续应用方向，其实际收益需要评测。

以下是按使用路径归纳的定位判断，标为 **Estimated**；它们不是特定产品的竞品测评。

| 读者原有的路径 | 我们集中补充的工作 | 对应价值主题 |
| --- | --- | --- |
| 阅读原论文，再自行整理推导和作者代码 | 将论文、关键推导、实现和运行说明放在同一案例中 | 理解发现的过程 |
| 跟随综述、教材或论文目录寻找研究方向 | 学科目录、先修知识、建议顺序和第一项动手任务相互连接 | 重走可验证的计算 |
| 自己或请 Agent 完成一次计算 | 保留生成材料、复现范围、评审状态和版本记录 | 让研究持续积累 |

优先服务学生的判断来自项目方（**User-provided**）。当前材料与这一需求匹配，
但学习效果、获取用户的渠道和实际触达成本尚未测量。第一步通过具体学习路径收集反馈，
再判断是否扩大投入。我们不使用未经比较验证的“唯一”“首个”或“最完整”。

## 叙事主线

论文浓缩了科学发现。后来者想从中开始研究，还需要理解省略的中间步骤、找到计算方法、
处理环境与数据，并判断算出的结果是否可信。

我们的产品主张是：随着论文复现 Agent 参与这些工作，可以把一次复现的推导、实现和
证据保留下来，成为下一位研究者的起点。PRAgent 承担论文复现；RunThePaper 负责把
可以共享的成果整理、连接和持续更新。

“可执行的科学史”指向这种积累方式：从论文进入一个发现，沿着推导与计算重走它，
再继续研究。目录与学习路径帮助人找到入口，论文时间线提供年代顺序，版本记录保留
材料如何变化。解释发现之间的联系和方法如何演变，是后续需要考证与编写的工作。

对学生，这是从兴趣进入研究的工作基础；对研究者，这是可供检查与扩展的已有工作；
对未来的科学智能体，这是可执行、可追溯的领域材料。AI 时代科研基础设施是这条
主线的长期价值，不能替代对每个案例的具体说明。

## 表达与一致性

- 产品名写作 **RunThePaper**；论文复现 Agent 写作 **PRAgent**。
  “可执行的科学史”是主定位，“AI 时代科研基础设施”解释长期价值。
- 用“理解、运行、核验、修改、继续研究”等具体动作说明价值，每次介绍提供一个可进入的案例。
- “更完整”指为论文文本补充推导、实现和证据的工作材料。具体覆盖范围由案例声明；
  文件齐全不代表科学验收完成，也不保证所有计算都适合普通电脑。
- 案例数量、复现成功率、独立评审状态分别表达。沿用审计的固定分母与原始定义。
- 论文年代、教学顺序、案例更新各有用途。历史影响与方法传承的关系需要证据。
- 学习效率和 AI 能力提升的效果进入[路线图](../ROADMAP.md)，等待测量后再成为宣传论据。

一致性检查：主张、主叙事与三条支柱都落到同一研究案例；中英文定位一致；
PRAgent 与 RunThePaper 职责清楚；当前材料、产品愿景和待验证效果分别标明。
后续项目介绍沿用核心表达；具体新证据通过 Git 修订本文件。
