# QC27｜公开资产与必要缺项

已核验正式发表版 17 页、arXiv v1 源包和文献 [32] 的 Clifford 表。源包只有稿件和 7 个图文件。正式版附录 A–D 已纳入，APS 独立补充入口返回 403。DataCite 按正式 DOI 查得的唯一关联是该预印本。作者团队公开数据仓的固定树 `a736a0233714a2316e79cf9d2b9453eb84106105` 只有另一项噪声谱实验的补充材料。作者先前的相关噪声实验数据有不同论文及实验对象。

正文给出脉冲构造、噪声强度、带宽和测量规模，足以做新的精确传播和解析检查。仍缺工程噪声的实际波形及分段时钟、原随机序列、实机组合门空闲脉冲及逐次读出。五离子同次相机标签缺失，不能从两张相关系数图反演联合统计。单离子基准的红色均值可从图重算，原序列级重复计数和误差区间所用统计未取得。
