# Numerical methods

1. 枚举满足周期或开边界 blockade 的 bitstring 基。
2. 通过单点翻转且邻居为空的规则构造稀疏 PXP Hamiltonian。
3. 对 L=18 OBC 全谱和 L=26 周期零动量扇区做精确对角化。
4. 直接由打印矩阵生成 MPS/SMA/MMA 振幅，并在需要时做平移或反演投影。
5. 从 H+ 递推生成全部 27 个 FSA 态。
6. 在 Xi 的完整 13 维非正交子空间求解广义本征问题。
7. 对 L=16,18,20,22,24,26 计算半链纠缠熵。

paper-scale 运行采用单线程 CPU，约 90.44 秒。最大扇区维数仅 5536/5399，A100 在本例不会降低端到端复杂度，反而增加数据搬运与环境开销。
