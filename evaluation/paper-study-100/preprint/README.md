## 可复算成果

Figure 1为重新设计并逐项核对的概念架构图；Figure 2将历史结论覆盖率按本文100篇名单重新对齐，并展示存档的核验状态；Figures 3-5由固定公开版本的数值数组重绘，没有运行原案例求解器，也没有复制作者原图。`build_evidence.py`读取公开Git对象，复算量子游走粒子数守恒残差和资源比例，保存输入哈希及结果摘要。物理模型、原始理论与源论文作者明确归属；报告贡献为实现、工作流与科研工件组织。

```bash
python build_evidence.py
python build_overview.py
python build_reason_audit.py
python build_diagnostic_followup.py
python build_responsibility_audit.py
bash build_report.sh
python package_arxiv.py
```

数值图环境沿用 `../manuscript/requirements.txt`。Figure 1保留已审阅的设计图；`build_figure1.py`使用 `reportlab==4.4.9`将原PNG无像素修改地封装为PDF。执行数据复算不会覆盖该设计。排版使用Pandoc和标准PDFLaTeX，没有本机系统字体、绝对文件路径或非标准期刊类依赖。打包工具在干净目录中解包并执行两次PDFLaTeX，检查每张引用图和100个队列身份。

## 总体复现图口径

全图保留100篇，不设置来源分组。历史数值结论等权覆盖率为40.9%，有测量论文的逐篇平均为57.8%；3篇没有该项测量，保留缺失。两者均不表示整篇论文完成率。图中核验状态来自同一冻结版本中的案例评估文件，历史覆盖表不覆盖后续或更严格的验收结论。逐篇、逐结论、逐检查源数据及文件哈希保存在 `anc/overview_*`，随arXiv草稿源包提供。

## 失败与待核验原因

正文按用户指定的四个责任领域归因：**论文本身、Agent、算力、实验设备**。59个可比较案例中，48个涉及论文信息或疑似论文结论差异，33个涉及Agent实现或工作流，10个涉及计算容量；类别重叠。实验设备原因未从现有诊断中单独建立，保留未确认，不能记成零。详情见[四类归因说明](四类归因说明.md)。

论文信息缺失不等于论文结论错误；Agent流程缺口不等于代码错误；未运行不自动等于算力不足。27条外部访问诊断暂不强分，包括付费补充材料、计算软件许可和未核验计算平台。责任映射保留100篇及59案的523条开放诊断，四份 `anc/responsibility_*` 随源包提供。旧六类 `anc/reason_*` 作为原始诊断台账保留。63个失败或待核验案例中，4个摘要与详细状态冲突，仍排除；全队列6个状态冲突未被修改。
