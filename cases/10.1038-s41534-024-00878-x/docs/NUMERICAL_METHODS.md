# Rerun / 复算

An analysis of the QFlow data discussed in the workshop report tests transfer across devices. The mixed-scan split gives 50.00% accuracy, and the two held-out device directions give 8.19% and 9.40%.

Use the [code instructions](../code/README.md). The default stages run into a new directory.

- `probe.py`

For the experimental split, obtain the NIST QFlow 2.0 experimental ZIP and run static_transfer.py with the configured path. The default run recomputes the exact known-label navigation control.
