## 新独立评审确认的候选

REV001（T001/T002）：正文的 2 ln(3) 与补充材料精确式 3^(-b) 不一致。精确推导给出 2/ln(3)=1.82047845，而正文值为 2.19722458，差 20.7%；相邻二格点 block 的精确比值是 1/3，正文值会预测 0.40242794。解析重推、独立 L=50 拟合、比值不变量和直接 MPS 交叉检查均支持除法形式。新 fresh-context 评审在包含参数来源合同的 bundle 上确认其为 paper_error_candidate。

REV002（T006/T007）：补充材料称打印的 bond-3 N/tilde-N 矩阵满足精确反演规范关系，但直接代入得到非零局域残差 0.00727511 和 0.34811319；L=26 的错误宇称权重为 1.158e-6 和 1.825e-4，远高于 1e-12 的精确对称容差。解析矩阵恒等式、独立直接态收缩和完整谱权重归一共同确认 paper_error_candidate。该问题不否定图中主要 overlap 峰值，只否定“打印参数给出精确反演量子数”这一陈述。
