展开参考态解释与本轮验证

在 t₁=t₂、偶数胞元数的有限周期链中，存在不衰减暗模。用 P 表示归一化暗模投影，三种合法稳态参考给出：

参考态暗模占据相对 .5I 的每胞元偏离量
C₀ = .5(I−P)0加 1/(2L)
Cₕ = .5I.5不变
C₁ = .5(I+P)1减 1/(2L)

Cₕ 是文中给出的合法稳态；C₁ 是我们所用满填充初态的有限链长时极限。C₀ 与公开周期链图线相容，但图线相容不能证明作者采用了 C₀ 或某种特定求解器。

直接 Lyapunov 求解和小系统独立 SVD 均得到 C₀；20 组链长与增益/损耗控制支持此机制。对应偏移为图 2(a)A 的 1/300、图 3(b) 的 1/120。图 3(a) 在 10–180 胞元 × 三种参考态中，仅 L=30、C₀ 满足全部端点误差带，早晚时间段判断一致。

本轮重新读取原始 EPS，使用全部刻度标定轴，并在原图时间点计算；没有自由拟合曲线平移或缩放。矩阵指数、仿射 ODE、SVD 截断和 80 位精度控制均已核对。

“该机制能解释图线”已有直接证据；“作者采用了此求解器”仍未确认。图 3(a) 的 L=30 是稳定的图线推断。它们不阻碍本轮计算，不归因为作者表达不清。有限链的稳态参考与具体初态的长时极限仍需区分。
