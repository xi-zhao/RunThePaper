# Formula Verification

All formula cards used by numerical code have a source anchor and an
independent identity or limiting-case check. `EQUATION_CARDS.json` is the
machine-readable authority; `outputs/checks/formula_verification.json` is
generated by the Harness.

| EQ-MPS | verified | all-zero point has unit norm; finite-ring state is explicitly normalized |
