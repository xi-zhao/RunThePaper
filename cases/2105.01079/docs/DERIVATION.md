# QC20 条件、训练与独立判别

三个能级的驱动以升降算符和 -320 MHz 的诊断非谐性实现。按公开单比特方案使用八段控制和 10 单元 tanh 隐层。每轮 64 个候选，300 轮，初始态取 $|0\rangle$，训练静态频差为 -3、0、3 MHz。只向策略返回阶段布居的 256 次二项计数。末段以 1、3、5 次重复的条件态重叠除以 $1+\ell^2$，两种计数各按 1024 次模拟。阶段布居、动作表、重复权重、Adam 步长和噪声均为本次设置。评估用确定的 −8 至 8 MHz 网格与投影迹失真。Cauchy 退火使用同一个物理模型、连续动作和另一温度设置，比较时注明调用数不同。谱分解和矩阵指数互核一段传播。

ZX 与控制比特的 $Z$ 相位对易。对 $|00\rangle$、$|10\rangle$，控制比特相位在每次重复后只产生全局相位。$Z$ 相位取 π 时，迹保真度为零。SWAP 的两测试态及其理想像张成三维空间。对正交补 $|--\rangle$ 加 π 相位不改变这些状态的任何重复读出，迹保真度降为 $1/4$。独立矩阵幂核对 1 至 64 次重复。结论约束直接重复测量的可识别性，未涉及独立 IRB 的实测数据。
