# 相干隧穿抑制：完整四次势模型

原文为作者大学网页保存的1991年出版扫描版，PRL67,516–519。模型H=p²/2−x²/4+x⁴/(64D)+xSsin(ωt)，D=2。极小值位于x=±sqrt(8D)=±4，局域谐振频率为1。初态为左井的谐振近似基态，不能用恰好由两个Floquet本征态拼成的理想局域态代替，否则会人为消除原图残余振荡。

谐振子基展开完整四次势并求本征态，在这些本征态基中积分一个驱动周期的传播矩阵U(T)。原文已经明确二能级近似不足，因而没有用Bessel二能级公式代替原计算。保留24、32、40个静态本征态做截止检查，同时以120/160维底层振子展开和有限差分Richardson外推独立核对低能谱。

本征值exp(−iεT)给出准能量模ω；绘图时选择离初始双重态能量最近的分支，保留ε→ε+nω的等价关系。传播n周期用原始U的本征相位，初态投影保持其真实截断权重，检查U的幺正性，不将每步态强制归一来掩盖误差。图1ω=E3−E2、S=10⁻⁴，计算前2×10⁵周期的生存概率及其频谱；S扫描重现三个主要准能级的避免交叉结构。

图2ω=.01，图注S=3.171×10⁻³，正文舍入为3.17×10⁻³，两者不混用。初态、自相关P、左井占据及n=458的密度全部计算，和原图P仍略低于1、左井占据接近1的实际结论比较。对长时间周期相位敏感的量，必须用截止对照而非只看单周期积分器的成功状态。
