# 线性近邻 QFT 的酉与统计核查

## 编译

采用大端输入和 QFT 正指数，输出按逻辑位反序。用 (CP(\theta)\sim RZ_i(\theta/2)RZ_j(\theta/2)RZZ_{ij}(-\theta/2))。同一线上位于 Hadamard 之前的 Z 旋转可移到输入边界，之后的移到输出边界。小角近似保留这些边界相位，只去掉 RZZ。内部 Hadamard 写成 (S\sqrt X S)（差整体相位）。保留两个端点的 Hadamard。

记 (C_i=CX(i,i+1))。先降序的相邻异或将后一位变为与前位之差，再以升序在一个 CP 行内累计，形成该行控制位和各目标位的奇偶。该奇偶上施加单线 RZ，再反向撤销。相邻两个 CP 行之间，与下一 Hadamard 只作用于不相交线的 CX 可移过它并取消。以 (\sqrt X) 替代下一 Hadamard 后，(C_{i+1}C_iC_{i+1}) 共轭保持第 (i+1) 位的 (X)；因此 (\sqrt X) 可移过三门，邻行再消去两个 CX。实际构造每个内行用半径 (\min(d,n-1-i))。(d=1) 的低 CX 对照直接分解相邻 CP。

卷积版在输入加一位零辅助，移到链尾之后做原降序异或，与反向的升序异或梯在这个输入子空间作用相同。最后一对 CX 复制和撤销最后一个数据位的计算基标签，在末端 Hadamard 之前完成。输入辅助在首位，输出辅助在末位。沿不相交线交换门得到保序的最晚排程。内部 CP 行使用平移相同的相位和 CX 序列，加入一条移动辅助的相邻边。末尾窗口随剩余比特数收缩。小系统完整矩阵比较取辅助零输入的所有列，分别检查辅助零输出和数据块。100 位有限宽核用 MPS 收缩真实生成的门串，核对范数、舍弃权重和指定输出概率。

## 门数与深度

深度定义为给每个双比特门一层、单比特门不增加双比特层数，仍保持同线因果次序。对卷积版本，表 I 的近似列取 (d=n-1) 后为 (n^2-3n+8)，完整列写 (n^2-3n-8)。构造得到前者。对 (d=1,n=9)，用独立逻辑 AQFT 计算末端测量 (Z) 逆向共轭与首输入 (Z) 的交换子，归一 Frobenius 范数 0.125。原卷积物理布局上两点相距 7 条边，故六层不能实现这项依赖。保留 d≥2 的排程适用域。

## 理想目标概率

周期输入按模整数取相位，避免把 100 位频率转换为浮点数后再求相位。设已测的正确前缀比特为 (b_i)，第 (j) 位因被删 RZZ 引起的相位误差为 (\delta_j=\sum_{i<j-d}\theta_{j-i}(1/2-b_i))。对理想目标的条件概率为 (\cos^2(\delta_j/2))，全串取积。该递推与门串 MPS 分开实现。错串在第一次分叉处的概率不超过 (\sin^2(\pi/2^{d+2}))，其余条件概率不超过 1。模型的最小目标概率由同号的最大相位偏差给出。比较全部小系统输入与大系统明确样本。

## 保真度

[公式来源的附录 A](https://arxiv.org/html/2403.09514v2#A1) 证明 ((E_k\sqrt{p_k})^2) 对应 QFT 后接测量的过程保真度。式 (2) 为有序不同样本对的 `sqrt(p_i*p_j)` 平均。精确条件概率、独立均匀抽取时，该项对频率抽样无偏。每个条件只有有限 shots，平方根的凹性使直接代入经验概率在理想二项模型下向下偏。合成偏差用二项分布精确求和，只核对机制。

若在理想 QFT 输出后加入一个非平凡对角 Z，所有计算基概率保持相同，和理想酉的迹重叠可以为零。读出校正后的数字仍对应测量型统计，无法由单一读出基确定酉过程保真度。将这一可识别性和论文的测量成功率分别记账。
