# Pontus-Mpemba：从论文到计算

权威数值源：PRL 135, 140404 (2025) 最终 OA PDF，包括 End Matter A1–A9 和图3–4。

标准 GKSL 约定是 `-i[H,rho] + sum Cmn (sigma_m rho sigma_n - {sigma_n sigma_m,rho}/2)`。
写 `rho=(I+r.sigma)/2`、`H=h.sigma`，利用 Pauli 乘法与迹恒等式得到
`rdot=M r+b`，其中 `M=2 Lambda`（A2），`b=-4 Im(C23,C31,C12)`。
本例 h1=h2=0，C12 实数、C13/C23 纯虚，所以 xy 平面闭合。
矩阵 M 的 12/21 元分别为 `2(-h3+ReC12)` 与 `2(h3+ReC12)`。

当 M 可逆时 `r*=solve(M,-b)`，精确解为 `r(t)=r*+exp(Mt)(r0-r*)`。
任意两个量子位态之间的迹距离是 `norm(r1-r2)/2`。
速度场由 `M r+b` 直接计算，不从原图追踪，也不读取作者数组。
两步协议在切换前演化辅助浴，切换后以当时的实际态作为终浴初态。
完成时间是 `tSI+tIF`，不能省略辅助制备时间；相同迹距离阈值下比较直接时间。

End Matter 明确先选择 r* 再用 `b=-2 Lambda r*` 构造浴。印刷矩阵的小数有限，
因此保留两个事先声明的计算：`printed` 原样使用印刷数字；
`stationary_constrained` 保留印刷实部及 h3，用给定 r* 重建纯虚部。
后者不是拟合，也不覆盖前者；需报告重建偏移是否落在 0.005 的舍入范围。
每个浴检查 C 半正定、|r*|<=1，所有轨迹检查密度矩阵正性及迹保持。

类别使用论文定义：切换态比同一时刻直接态更近为 weak A；
初态距离大于切换距离、切换距离大于直接距离为 weak B；
切换距离大于初态距离为 strong。距离类别本身不证明加速，另算含制备时间的速度比。
这个 strong 术语不等同于一般 Mpemba 文献的慢模系数严格为零。

独立核验：不用 M 的构造，直接在 2x2 密度矩阵上展开 GKSL，
建立 4x4 Liouvillian 或高精度 ODE，比较演化与分段协议。
