# Heterogeneous fault-tolerant architectures

The published appendix was used to reconstruct the QPU, memory and link resource counts. At 1,000 logical qubits the baseline uses 59.56 and 138.58 times as many physical qubits as STQM and RAQM respectively. Two RSA configurations contain about 381,000 and 190,000 physical qubits. [Paper](https://doi.org/10.1088/1367-2630/aeb71b)
