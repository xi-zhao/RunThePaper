# Paper map

## Scientific claim

Polarized source xenon spins produce an oscillatory pseudomagnetic field. A
second xenon ensemble acts as a narrow-band resonant amplifier, and an optimal
template filter estimates any exotic field. The null result is converted into
a mass-dependent bound on the neutron pseudoscalar coupling.
