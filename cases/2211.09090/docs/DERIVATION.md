# QC18 数学与数值验收

单比特返回概率为 `1 − Ω² sin²(T sqrt(Δ²+Ω²)/2)/(Δ²+Ω²)`。理想 ±π/2 脉冲使用名义 Ω，实际转角保留 Ω 的偏差。按单比特和双比特 Hamiltonian 对分段控制做时间有序乘积。对于标注为名义单位的模拟图用角频率数值，离子阱图用 2π 将 Hz 转为 rad/s。公开波形由矢量图分段坐标得到。

Bernoulli 投影的 Fisher 矩阵是梯度外积除以 `P₀(1−P₀)`，每个单一设置至多为秩一。随 T 增长，梯度的相位导数为线性主项，给出平方的 Fisher 标度。返回概率的幅度导数有单独的低阶项。两种探针的雅可比满秩提供局部可区分性。固定 Rabi 的等径参数仍可经振幅因子区别。本文选择两组等径近邻作为具体检查，有限噪声下小差值可以实用上不可区分。10 段相位可变探针给出的另一梯度方向说明停滞依赖脉冲设置和统计精度。

后验的对数似然由每轮独立观测累加。标准差为 σ 的高斯误差应使用 `(p−m)²/(2σ²)`。固定版式 (6) 和 (10) 的分母写为 `(2σ)²`，若逐字采用，等效标准差是 √2σ。一个 σ 的残差在两式中的相对权重分别为 0.60653 和 0.77880。复算分别运行两种规则，实际论文程序的选择未由排印确定。对式 (8) 的拒绝采样，后验密度与提议密度之比需要适当包络。均值与方差匹配的高斯提议对所给双峰例在峰点的比值为 3.30。比例常数是否能提供全局包络取决于目标和提议。

预期后验协方差的迹等于先验协方差迹减去后验均值的方差迹。固定先验样本、对观测值积分后，与逐点构造条件后验协方差的算法核对。按相同初始分布和不同公开条件运行模拟。使用 1,800 或 2,200 个粒子，重抽后用基于全部已有似然的 Metropolis 更新，选脉冲时用最多 384 个粒子。脉冲时长及 10 段控制在有限候选网格上按预期方差下降选优，再试局部扰动。原文的连续优化和随机种子未知。程序在选择后才生成下一次观测，比较样本数、总脉冲时长与后验误差分别输出。

修改 Fisher 的离散对照按固定版式 (B3) 至 (B5) 计算，取失谐为符号翻转的检测方向、α=1、β=0.1。三个时长的符号翻转概率随振荡上升。它的值会受先验方向和阈值影响，该对照保留未惩罚和修正后的结果。
