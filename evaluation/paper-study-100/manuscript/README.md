## 复算与排版

图表环境：Python 3.12，依赖版本见 `requirements.txt`；排版使用 Pandoc 3.9、XeLaTeX / TeX Live 2026，字体为 Times New Roman、Arial 和 Courier New。其他平台可在 `template.tex` 中替换等价字体。

```bash
python build_figures.py
bash build_pdf.sh
python verify_manuscript.py
```

所有脚本都只分析本研究已有的公开记录，不运行论文案例。构建PDF使用临时目录，不在仓库保留辅助排版文件。PDF版本记录在 `validation.json`，后续正文修改需要重新生成PDF和验证记录。
