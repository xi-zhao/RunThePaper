## 从哈密顿量到可观察量

论文的 RWA 哈密顿量保守总激发数。把系统和 M 个浴模的算符组成向量，其单粒子矩阵为箭头矩阵 h：系统频率为 10，浴频率在 (0,50]，系统与每个浴模耦合。精确海森堡演化是 `b(t)=exp(−i h t)b(0)`。因此无需截断玻色 Fock 空间，也没有额外的 Born–Markov 近似。

采用原文的 M=350、双模压缩 r=4、tmax=21。图 2 使用 Ohmic 谱 `J(ω)=αω exp(−ω/15)`，T=0,1,2，dt=0.0209；图 3 使用 `J(ω)=αω³ exp(−ω/3)`，T=0,2,4，dt=0.0417。原文没有说明离散节点的具体定义，我们明确选择 `ω_j=j×50/M`、`g_j²=J(ω_j)×50/M`，并单独检查中点网格和更多浴模。

由演化矩阵第一行得到透射率 η 和热噪声 q，初态的系统—辅助模协方差归结为三个标量 a、b、c。部分转置的最小辛本征值给出对数负性。计算使用避免大压缩下相减消去的等价公式，保持 `log₂` 与真空协方差 I 的约定。最后按论文定义计算 `I(E)=2×Σ正的纠缠增量`，不是只累加一次回升。完整逐步推导见 derivation.md，不同方法的解析检查见 analytic_checks.md。

强耦合模型还有物理适用边界。由 Schur 补可直接证明，当 `10 < Σg_j²/ω_j` 时，h 有负本征值。图 2 的本次网格临界 α=0.69463；α=1.5 时最小本征值为 −3.9788。多玻色子 H 因此无能量下界，但 h 仍是厄米的，指定初态的有限时间演化仍幺正，不是指数动力学不稳定。图 3 在给定范围内未跨过其临界 α≈0.18519。本次不改写论文哈密顿量，只限定强耦合结果的解释。模型边界推导

## 解析结论与固定版本的表述问题

- 正则、有限维、时间局域情形，非负率 GKSL 表示与 CP 可分传播子的对应得到支持。这里 Markov 性采用论文后半部分的 CP 可分意义，不把时间齐次半群与所有时间依赖情形混同。
- 辅助系统隔离时，局部 CPTP 映射不能增加纠缠，故 I(E)>0 是充分条件。I(E)=0 不能作反向判断；低于纠缠破坏阈值的去极化通道提供明确的漏检控制。
- 归一化 Choi 矩阵的迹范数等于 1 当且仅当其非负。已知可逆映射允许构造中间传播子。原文已指出不可逆时间点的重建困难，本次不宣称解决它。
- Eq.(4) 的 `g=max(0,−2γ)` 和负率不可积导致发散的结论成立。自发辐射的简短类比亦作了代数核查，没有把被引用论文的图列为新增任务。
- 单点 `g(t)=0` 不能保证随后有限区间的传播子为 CP。例如原文退相干模型取 γ=1−t，在 t=1 处 g=0，但任意短 ε>0 的中间 Choi 迹范数为 exp(ε²)>1。这个边界不破坏积分指标对随后区间的检测。
- 固定 v2 图 3 的第一内部 x 刻度印成 0.5，应为 0.05。正文所述“较大 α 下指标随温度增加”的文字，在两图末端与图线相反。图 1 的回升箭头属于示意；实际数值必须采用正文总变差公式的两倍回升量，不能把示意高度当作标定数据。
